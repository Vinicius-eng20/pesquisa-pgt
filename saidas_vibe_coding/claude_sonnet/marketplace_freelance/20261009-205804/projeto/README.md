# Marketplace de Serviços Freelance

Sistema completo de marketplace para contratação de serviços freelance.

## Requisitos

- Node.js 18+ instalado
- Navegador web moderno

## Instalação

```bash
npm install
```

## Executar o projeto

```bash
npm start
```

O site estará disponível em: http://localhost:3000

## Primeiro Acesso

### Conta Administrador (já criada):
- Email: admin@marketplace.com
- Senha: Admin123!

### Criar contas de usuários:
Clique em "Cadastrar" na página inicial e preencha o formulário.

## Funcionalidades

### Usuários (Freelancers/Clientes):
- Publicar serviços que oferece
- Contratar serviços de outros usuários
- Ver contratos em que participa
- Editar perfil

### Administrador:
- Aprovar ou remover serviços publicados
- Suspender contas de usuários
- Ver todos os serviços e contratos
- Painel completo de administração

## Notas

- Todos os dados são salvos no arquivo `database.json`
- O site funciona em qualquer dispositivo (responsivo)
- Não necessita conexão com serviços externos
