# Instalar e rodar (resumo)
1. Instale Python (3.8 ou mais novo).
2. No terminal, na pasta do projeto:
   - Windows: `pip install flask`
   - macOS/Linux: `pip3 install flask`
3. Inicie o servidor:
   - `python app.py`  (ou `python3 app.py`)
4. Abra no navegador: http://localhost:5000
