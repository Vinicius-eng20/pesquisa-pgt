# Plataforma de Cursos Online

Este é um site completo de plataforma de cursos online com sistema de matrículas. Funciona com qualquer navegador moderno (computador e celular).

## Requisitos

- Node.js (versão 14 ou superior)
- PostgreSQL (versão 12 ou superior)

## Instalação

### 1. Instalar dependências

```bash
npm install
```

### 2. Configurar o banco de dados

Crie um banco de dados PostgreSQL e execute o script `database.sql`:

```bash
psql -U seu_usuario -d postgres -f database.sql
```

### 3. Configurar variáveis de ambiente

Copie o arquivo `.env.example` para `.env` e edite com suas configurações:

```bash
cp .env.example .env
```

Edite o arquivo `.env`:
```
DB_HOST=localhost
DB_PORT=5432
DB_USER=seu_usuario
DB_PASSWORD=sua_senha
DB_NAME=cursos_online
JWT_SECRET=uma_chave_secreta_bem_segura_aqui
PORT=3000
```

### 4. Executar o projeto

```bash
npm start
```

O site estará disponível em `http://localhost:3000`

## Como usar

### Primeiro acesso

1. Acesse o site no navegador
2. Clique em "Criar conta"
3. Preencha seus dados
4. O primeiro usuário criado será automaticamente o administrador

### Como aluno

- Visualize todos os cursos disponíveis
- Clique em "Matricular" para se inscrever em um curso
- Acesse "Meus Cursos" para ver suas matrículas

### Como administrador

- Acesse o painel administrativo
- Cadastre novos cursos
- Edite cursos existentes
- Remova cursos
- Veja todas as matrículas de todos os alunos
- Cancele matrículas

## Para deixar disponível na internet

Para que o site funcione na internet, você precisa hospedá-lo em um servidor. Opções:

1. **Servidor próprio (VPS)**: Alugue um VPS (DigitalOcean, Linode, AWS EC2) e siga os passos acima
2. **Heroku**: Faça deploy direto com PostgreSQL addon
3. **Railway**: Suporte nativo para Node.js + PostgreSQL

## Tecnologias

- Backend: Node.js + Express
- Banco de dados: PostgreSQL
- Frontend: HTML, CSS, JavaScript (vanilla)
- Autenticação: JWT (JSON Web Tokens)

=== database.sql ===
```sql
-- Criar banco de dados
CREATE DATABASE cursos_online;

-- Conectar ao banco
\c cursos_online;

-- Tabela de usuários
CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nome VARCHAR(255) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    senha VARCHAR(255) NOT NULL,
    admin BOOLEAN DEFAULT FALSE,
    criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabela de cursos
CREATE TABLE cursos (
    id SERIAL PRIMARY KEY,
    titulo VARCHAR(255) NOT NULL,
    descricao TEXT,
    instrutor VARCHAR(255),
    duracao VARCHAR(100),
    criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    atualizado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabela de matrículas
CREATE TABLE matriculas (
    id SERIAL PRIMARY KEY,
    usuario_id INTEGER REFERENCES usuarios(id) ON DELETE CASCADE,
    curso_id INTEGER REFERENCES cursos(id) ON DELETE CASCADE,
    data_matricula TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(usuario_id, curso_id)
);

-- Índices para melhor performance
CREATE INDEX idx_matriculas_usuario ON matriculas(usuario_id);
CREATE INDEX idx_matriculas_curso ON matriculas(curso_id);
CREATE INDEX idx_usuarios_email ON usuarios(email);
```

=== server.js ===
```javascript
require('dotenv').config();
const express = require('express');
const cors = require('cors');
const path = require('path');
const { Pool } = require('pg');
const bcrypt = require('bcrypt');
const jwt = require('jsonwebtoken');

const app = express();
const PORT = process.env.PORT || 3000;

// Configuração do banco de dados
const pool = new Pool({
  host: process.env.DB_HOST,
  port: process.env.DB_PORT,
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME,
});

// Middlewares
app.use(cors());
app.use(express.json());
app.use(express.static('public'));

// Middleware de autenticação
const autenticar = (req, res, next) => {
  const token = req.headers['authorization']?.split(' ')[1];
  
  if (!token) {
    return res.status(401).json({ erro: 'Token não fornecido' });
  }

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.usuario = decoded;
    next();
  } catch (erro) {
    return res.status(401).json({ erro: 'Token inválido' });
  }
};

// Middleware para verificar se é admin
const verificarAdmin = (req, res, next) => {
  if (!req.usuario.admin) {
    return res.status(403).json({ erro: 'Acesso negado. Apenas administradores.' });
  }
  next();
};

// ===== ROTAS DE AUTENTICAÇÃO =====

// Registrar usuário
app.post('/api/registrar', async (req, res) => {
  const { nome, email, senha } = req.body;

  if (!nome || !email || !senha) {
    return res.status(400).json({ erro: 'Todos os campos são obrigatórios' });
  }

  try {
    // Verificar se email já existe
    const emailExiste = await pool.query(
      'SELECT id FROM usuarios WHERE email = $1',
      [email]
    );

    if (emailExiste.rows.length > 0) {
      return res.status(400).json({ erro: 'Email já cadastrado' });
    }

    // Verificar se é o primeiro usuário (será admin)
    const totalUsuarios = await pool.query('SELECT COUNT(*) FROM usuarios');
    const isPrimeiroUsuario = parseInt(totalUsuarios.rows[0].count) === 0;

    // Hash da senha
    const senhaHash = await bcrypt.hash(senha, 10);

    // Inserir usuário
    const resultado = await pool.query(
      'INSERT INTO usuarios (nome, email, senha, admin) VALUES ($1, $2, $3, $4) RETURNING id, nome, email, admin',
      [nome, email, senhaHash, isPrimeiroUsuario]
    );

    const usuario = resultado.rows[0];

    // Gerar token
    const token = jwt.sign(
      { id: usuario.id, email: usuario.email, admin: usuario.admin },
      process.env.JWT_SECRET,
      { expiresIn: '7d' }
    );

    res.status(201).json({
      mensagem: 'Usuário criado com sucesso',
      token,
      usuario: {
        id: usuario.id,
        nome: usuario.nome,
        email: usuario.email,
        admin: usuario.admin
      }
    });
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao criar usuário' });
  }
});

// Login
app.post('/api/login', async (req, res) => {
  const { email, senha } = req.body;

  if (!email || !senha) {
    return res.status(400).json({ erro: 'Email e senha são obrigatórios' });
  }

  try {
    const resultado = await pool.query(
      'SELECT id, nome, email, senha, admin FROM usuarios WHERE email = $1',
      [email]
    );

    if (resultado.rows.length === 0) {
      return res.status(401).json({ erro: 'Email ou senha incorretos' });
    }

    const usuario = resultado.rows[0];

    // Verificar senha
    const senhaCorreta = await bcrypt.compare(senha, usuario.senha);

    if (!senhaCorreta) {
      return res.status(401).json({ erro: 'Email ou senha incorretos' });
    }

    // Gerar token
    const token = jwt.sign(
      { id: usuario.id, email: usuario.email, admin: usuario.admin },
      process.env.JWT_SECRET,
      { expiresIn: '7d' }
    );

    res.json({
      mensagem: 'Login realizado com sucesso',
      token,
      usuario: {
        id: usuario.id,
        nome: usuario.nome,
        email: usuario.email,
        admin: usuario.admin
      }
    });
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao fazer login' });
  }
});

// ===== ROTAS DE CURSOS =====

// Listar todos os cursos (público)
app.get('/api/cursos', async (req, res) => {
  try {
    const resultado = await pool.query(
      'SELECT * FROM cursos ORDER BY criado_em DESC'
    );
    res.json(resultado.rows);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao buscar cursos' });
  }
});

// Buscar curso específico
app.get('/api/cursos/:id', async (req, res) => {
  try {
    const resultado = await pool.query(
      'SELECT * FROM cursos WHERE id = $1',
      [req.params.id]
    );

    if (resultado.rows.length === 0) {
      return res.status(404).json({ erro: 'Curso não encontrado' });
    }

    res.json(resultado.rows[0]);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao buscar curso' });
  }
});

// Criar curso (admin)
app.post('/api/cursos', autenticar, verificarAdmin, async (req, res) => {
  const { titulo, descricao, instrutor, duracao } = req.body;

  if (!titulo) {
    return res.status(400).json({ erro: 'Título é obrigatório' });
  }

  try {
    const resultado = await pool.query(
      'INSERT INTO cursos (titulo, descricao, instrutor, duracao) VALUES ($1, $2, $3, $4) RETURNING *',
      [titulo, descricao, instrutor, duracao]
    );

    res.status(201).json(resultado.rows[0]);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao criar curso' });
  }
});

// Atualizar curso (admin)
app.put('/api/cursos/:id', autenticar, verificarAdmin, async (req, res) => {
  const { titulo, descricao, instrutor, duracao } = req.body;

  try {
    const resultado = await pool.query(
      'UPDATE cursos SET titulo = $1, descricao = $2, instrutor = $3, duracao = $4, atualizado_em = CURRENT_TIMESTAMP WHERE id = $5 RETURNING *',
      [titulo, descricao, instrutor, duracao, req.params.id]
    );

    if (resultado.rows.length === 0) {
      return res.status(404).json({ erro: 'Curso não encontrado' });
    }

    res.json(resultado.rows[0]);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao atualizar curso' });
  }
});

// Deletar curso (admin)
app.delete('/api/cursos/:id', autenticar, verificarAdmin, async (req, res) => {
  try {
    const resultado = await pool.query(
      'DELETE FROM cursos WHERE id = $1 RETURNING id',
      [req.params.id]
    );

    if (resultado.rows.length === 0) {
      return res.status(404).json({ erro: 'Curso não encontrado' });
    }

    res.json({ mensagem: 'Curso deletado com sucesso' });
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao deletar curso' });
  }
});

// ===== ROTAS DE MATRÍCULAS =====

// Matricular em um curso (aluno autenticado)
app.post('/api/matriculas', autenticar, async (req, res) => {
  const { curso_id } = req.body;
  const usuario_id = req.usuario.id;

  if (!curso_id) {
    return res.status(400).json({ erro: 'ID do curso é obrigatório' });
  }

  try {
    // Verificar se curso existe
    const cursoExiste = await pool.query(
      'SELECT id FROM cursos WHERE id = $1',
      [curso_id]
    );

    if (cursoExiste.rows.length === 0) {
      return res.status(404).json({ erro: 'Curso não encontrado' });
    }

    // Verificar se já está matriculado
    const jaMatriculado = await pool.query(
      'SELECT id FROM matriculas WHERE usuario_id = $1 AND curso_id = $2',
      [usuario_id, curso_id]
    );

    if (jaMatriculado.rows.length > 0) {
      return res.status(400).json({ erro: 'Você já está matriculado neste curso' });
    }

    // Criar matrícula
    const resultado = await pool.query(
      'INSERT INTO matriculas (usuario_id, curso_id) VALUES ($1, $2) RETURNING *',
      [usuario_id, curso_id]
    );

    res.status(201).json(resultado.rows[0]);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao realizar matrícula' });
  }
});

// Listar matrículas do usuário logado
app.get('/api/minhas-matriculas', autenticar, async (req, res) => {
  try {
    const resultado = await pool.query(
      `SELECT m.id, m.data_matricula, c.id as curso_id, c.titulo, c.descricao, c.instrutor, c.duracao
       FROM matriculas m
       JOIN cursos c ON m.curso_id = c.id
       WHERE m.usuario_id = $1
       ORDER BY m.data_matricula DESC`,
      [req.usuario.id]
    );

    res.json(resultado.rows);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao buscar matrículas' });
  }
});

// Listar todas as matrículas (admin)
app.get('/api/matriculas', autenticar, verificarAdmin, async (req, res) => {
  try {
    const resultado = await pool.query(
      `SELECT m.id, m.data_matricula, 
              u.id as usuario_id, u.nome as usuario_nome, u.email as usuario_email,
              c.id as curso_id, c.titulo as curso_titulo
       FROM matriculas m
       JOIN usuarios u ON m.usuario_id = u.id
       JOIN cursos c ON m.curso_id = c.id
       ORDER BY m.data_matricula DESC`
    );

    res.json(resultado.rows);
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao buscar matrículas' });
  }
});

// Cancelar matrícula (admin)
app.delete('/api/matriculas/:id', autenticar, verificarAdmin, async (req, res) => {
  try {
    const resultado = await pool.query(
      'DELETE FROM matriculas WHERE id = $1 RETURNING id',
      [req.params.id]
    );

    if (resultado.rows.length === 0) {
      return res.status(404).json({ erro: 'Matrícula não encontrada' });
    }

    res.json({ mensagem: 'Matrícula cancelada com sucesso' });
  } catch (erro) {
    console.error(erro);
    res.status(500).json({ erro: 'Erro ao cancelar matrícula' });
  }
});

// Servir o frontend
app.get('*', (req, res) => {
  res.sendFile(path.join(__dirname, 'public', 'index.html'));
});

// Iniciar servidor
app.listen(PORT, () => {
  console.log(`Servidor rodando na porta ${PORT}`);
  console.log(`Acesse: http://localhost:${PORT}`);
});
```

function mostrarLogin() {
    document.getElementById('login-form').classList.remove('hidden');
    document.getElementById('registro-form').classList.add('hidden');
    document.querySelectorAll('.tab-btn').forEach(btn => btn.classList.remove('active'));

    document.getElementById('registro-form').classList.remove('hidden');

async function fazerLogin(event) {
    event.preventDefault();
    
    const email = document.getElementById('login-email').value;
    const senha = document.getElementById('login-senha').value;
    const erroEl = document.getElementById('login-erro');

    try {
        const response = await fetch('/api/login', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ email, senha })
        });

        const data = await response.json();

        if (!response.ok) {
            erroEl.textContent = data.erro || 'Erro ao fazer login';
            return;
        }

        token = data.token;
        usuario = data.usuario;
        localStorage.setItem('token', token);
        localStorage.setItem('usuario', JSON.stringify(usuario));

        mostrarTelaPrincipal();
    } catch (erro) {
        erroEl.textContent = 'Erro ao conectar com o servidor';
    }
}

async function fazerRegistro(event) {
    event.preventDefault();
    
    const nome = document.getElementById('registro-nome').value;
    const email = document.getElementById('registro-email').value;
    const senha = document.getElementById('registro-senha').value;
    const erroEl = document.getElementById('registro-erro');

    try {
        const response = await fetch('/api/registrar', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ nome, email, senha })
        });

        const data = await response.json();

        if (!response.ok) {
            erroEl.textContent = data.erro || 'Erro ao criar conta';
            return;
        }

        token = data.token;
        usuario = data.usuario;
        localStorage.setItem('token', token);
        localStorage.setItem('usuario', JSON.stringify(usuario));

        mostrarTelaPrincipal();
    } catch (erro) {
        erroEl.textContent = 'Erro ao conectar com o servidor';
    }
}

async function carregarCursos() {
    try {
        const response = await fetch('/api/cursos');
        const cursos = await response.json();

        const matriculas = await fetchMinhasMatriculas();
        const cursosMatriculados = matriculas.map(m => m.curso_id);

        const container = document.getElementById('lista-cursos');
        
        if (cursos.length === 0) {
            container.innerHTML = '<p>Nenhum curso disponível no momento.</p>';
            return;
        }

        container.innerHTML = cursos.map(curso => {
            const jaMatriculado = cursosMatriculados.includes(curso.id);
            
            return `
                <div class="curso-card">
                    <h3>${curso.titulo}</h3>
                    <p>${curso.descricao || 'Sem descrição'}</p>
                    <p class="instrutor">Instrutor: ${curso.instrutor || 'Não informado'}</p>
                    <p class="duracao">Duração: ${curso.duracao || 'Não informada'}</p>
                    <button 
                        onclick="matricular(${curso.id})" 
                        ${jaMatriculado ? 'disabled' : ''}
                    >
                        ${jaMatriculado ? 'Matriculado' : 'Matricular'}
                    </button>
                </div>
            `;
        }).join('');
    } catch (erro) {
        console.error('Erro ao carregar cursos:', erro);
    }
}

async function matricular(cursoId) {
    try {
        const response = await fetch('/api/matriculas', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${token}`
            },
            body: JSON.stringify({ curso_id: cursoId })
        });

        const data = await response.json();

        if (!response.ok) {
            alert(data.erro || 'Erro ao realizar matrícula');
            return;
        }

        alert('Matrícula realizada com sucesso!');
        carregarCursos();
    } catch (erro) {
        alert('Erro ao conectar com o servidor');
    }
}

function mostrarFormCurso(curso = null) {
    const modal = document.getElementById('form-curso');
    const titulo = document.getElementById('form-curso-titulo');
    
    if (curso) {

        document.getElementById('curso-id').value = curso.id;
        document.getElementById('curso-titulo').value = curso.titulo;

        document.getElementById('curso-instrutor').value = curso.instrutor || '';

        document.getElementById('curso-descricao').value = '';

        document.getElementById('curso-duracao').value = '';

    modal.classList.remove('hidden');

async function salvarCurso(event) {
    event.preventDefault();
    
    const id = document.getElementById('curso-id').value;
    const dados = {
        titulo: document.getElementById('curso-titulo').value,
        descricao: document.getElementById('curso-descricao').value,
        instrutor: document.getElementById('curso-instrutor').value,
        duracao: document.getElementById('curso-duracao').value
    };

    try {
        const url = id ? `/api/cursos/${id}` : '/api/cursos';
        const method = id ? 'PUT' : 'POST';

        const response = await fetch(url, {
            method,
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${token}`
            },
            body: JSON.stringify(dados)
        });

        if (!response.ok) {
            const data = await response.json();
            alert(data.erro || 'Erro ao salvar curso');
            return;
        }

        alert(id ? 'Curso atualizado com sucesso!' : 'Curso criado com sucesso!');
        fecharFormCurso();
        carregarCursosAdmin();
    } catch (erro) {
        alert('Erro ao conectar com o servidor');
    }
}

async function deletarCurso(id) {
    if (!confirm('Tem certeza que deseja remover este curso? Todas as matrículas serão canceladas.')) {
        return;
    }

    try {
        const response = await fetch(`/api/cursos/${id}`, {
            method: 'DELETE',
            headers: { 'Authorization': `Bearer ${token}` }
        });

        if (!response.ok) {
            const data = await response.json();
            alert(data.erro || 'Erro ao remover curso');
            return;
        }

        alert('Curso removido com sucesso!');
        carregarCursosAdmin();
    } catch (erro) {
        alert('Erro ao conectar com o servidor');
    }
}
