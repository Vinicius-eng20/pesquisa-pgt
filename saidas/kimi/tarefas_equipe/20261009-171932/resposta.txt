# Sistema de Gestão de Tarefas de Equipe

Este é um sistema completo e funcional, pronto para uso imediato na internet. Não requer configurações complexas, contas em serviços externos ou conhecimento técnico avançado para começar a usar.

## Pré-requisitos

Apenas o **Node.js** instalado no computador ou servidor onde o site vai rodar.
- Baixe e instale em: https://nodejs.org/ (versão LTS recomendada)
- Verifique se instalou abrindo o terminal e digitando: `node -v`

## Como instalar e executar

1.  **Baixe ou clone os arquivos** para uma pasta no seu computador ou servidor.
2.  **Abra o terminal** (Prompt de Comando no Windows, Terminal no Mac/Linux) e navegue até essa pasta.
3.  **Instale as dependências** (bibliotecas necessárias) digitando:
    ```bash
    npm install
    ```
4.  **Inicie o servidor** digitando:
    ```bash
    npm start
    ```
5.  **Acesse o site**:
    - No mesmo computador: abra o navegador e vá para `http://localhost:3000`
    - De outros computadores ou celulares na mesma rede: use o IP do computador onde o servidor está rodando (ex: `http://192.168.1.10:3000`)
    - Para acesso pela internet (qualquer lugar): você precisará hospedar este projeto em um servidor com IP público ou usar um serviço de hospedagem Node.js (como Render, Railway, VPS, etc.). O sistema funciona de forma independente, sem depender de bancos de dados externos.

## Primeiro Acesso (Importante)

O sistema cria automaticamente um usuário **Gerente** padrão na primeira vez que é executado:

- **Usuário:** `admin`
- **Senha:** `admin123`

**Recomendação de Segurança:** Assim que entrar pela primeira vez, vá em "Gerenciar Membros", edite o usuário `admin` e altere a senha.

## Como usar

1.  **Login:** Entre com `admin` / `admin123`.
2.  **Criar Membros:** No painel do gerente, clique em "Gerenciar Membros" e adicione as pessoas da sua equipe. Defina um nome de usuário e senha para cada um.
3.  **Criar Tarefas:** O gerente pode criar tarefas e atribuir a qualquer membro. Membros também podem criar tarefas para si mesmos.
4.  **Acesso dos Membros:** Cada membro entra com sua própria conta e vê apenas suas tarefas (ou pode ver todas se for gerente).
5.  **Sincronização:** Tudo é salvo automaticamente no servidor. Se você criar uma tarefa no computador, ela aparecerá no celular ao atualizar a página. Se um membro atualizar o status, o gerente vê a mudança.

## Estrutura de Dados

Os dados são salvos em arquivos locais na pasta `data/`:
- `users.json`: Lista de usuários e permissões.
- `tasks.json`: Lista de todas as tarefas.

**Não apague a pasta `data/`** enquanto o sistema estiver em uso, pois isso apagará todas as informações.

## Solução de Problemas

- **Erro "Port already in use":** A porta 3000 está ocupada. Feche outros programas que usem essa porta ou altere a porta no arquivo `server.js` (linha `const PORT = 3000;`).
- **Não consigo acessar de outro dispositivo:** Verifique se o firewall do computador permite conexões na porta 3000. Certifique-se de que ambos estão na mesma rede Wi-Fi.
- **Esqueci a senha do admin:** Pare o servidor, delete o arquivo `data/users.json` e reinicie o servidor. Isso recriará o usuário admin padrão (mas apagará os outros usuários).

const express = require('express');
const bcrypt = require('bcryptjs');
const jwt = require('jsonwebtoken');
const cors = require('cors');
const bodyParser = require('body-parser');
const fs = require('fs');
const path = require('path');
const { v4: uuidv4 } = require('uuid');

const app = express();
const PORT = process.env.PORT || 3000;
const JWT_SECRET = process.env.JWT_SECRET || 'sua-chave-secreta-muito-segura-mude-isso-em-producao';
const DATA_DIR = path.join(__dirname, 'data');
const USERS_FILE = path.join(DATA_DIR, 'users.json');
const TASKS_FILE = path.join(DATA_DIR, 'tasks.json');

// Middleware
app.use(cors());
app.use(bodyParser.json());
app.use(express.static('public'));

// Garantir que o diretório de dados existe

// Inicializar arquivos de dados se não existirem
function initializeData() {
    if (!fs.existsSync(USERS_FILE)) {
        const adminPassword = bcrypt.hashSync('admin123', 10);

            {

initializeData();

// Helpers para ler/escrever dados
function readUsers() {
    try {
        const data = fs.readFileSync(USERS_FILE, 'utf8');
        return JSON.parse(data);
    } catch (error) {
        return [];
    }
}

function writeUsers(users) {
    fs.writeFileSync(USERS_FILE, JSON.stringify(users, null, 2));
}

function readTasks() {
    try {
        const data = fs.readFileSync(TASKS_FILE, 'utf8');
        return JSON.parse(data);
    } catch (error) {
        return [];
    }
}

function writeTasks(tasks) {
    fs.writeFileSync(TASKS_FILE, JSON.stringify(tasks, null, 2));
}

// Middleware de autenticação
function authenticateToken(req, res, next) {
    const authHeader = req.headers['authorization'];
    const token = authHeader && authHeader.split(' ')[1];

    if (!token) {
        return res.status(401).json({ error: 'Acesso negado. Token não fornecido.' });
    }

    jwt.verify(token, JWT_SECRET, (err, user) => {
        if (err) {
            return res.status(403).json({ error: 'Token inválido ou expirado.' });
        }
        req.user = user;
        next();
    });
}

// Middleware para verificar se é gerente
function requireManager(req, res, next) {
    if (req.user.role !== 'manager') {
        return res.status(403).json({ error: 'Acesso restrito a gerentes.' });
    }
    next();
}

// Login
app.post('/api/login', (req, res) => {
    const { username, password } = req.body;
    
    if (!username || !password) {
        return res.status(400).json({ error: 'Usuário e senha são obrigatórios.' });
    }

    const users = readUsers();
    const user = users.find(u => u.username === username);

    if (!user || !bcrypt.compareSync(password, user.password)) {
        return res.status(401).json({ error: 'Usuário ou senha incorretos.' });
    }

    const token = jwt.sign(
        { id: user.id, username: user.username, role: user.role, name: user.name },
        JWT_SECRET,
        { expiresIn: '24h' }
    );

    res.json({
        token,
        user: {
            id: user.id,
            username: user.username,
            name: user.name,
            role: user.role
        }
    });
});

// Verificar token (para manter sessão)
app.get('/api/me', authenticateToken, (req, res) => {
    const users = readUsers();
    const user = users.find(u => u.id === req.user.id);
    
    if (!user) {
        return res.status(404).json({ error: 'Usuário não encontrado.' });

    });

app.get('/api/users', authenticateToken, requireManager, (req, res) => {
    const users = readUsers();
    const safeUsers = users.map(u => ({
        id: u.id,
        username: u.username,
        name: u.name,
        role: u.role,
        createdAt: u.createdAt
    }));
    res.json(safeUsers);

// Criar novo usuário (apenas gerente)
app.post('/api/users', authenticateToken, requireManager, (req, res) => {
    const { username, password, name, role } = req.body;

    if (!username || !password || !name) {
        return res.status(400).json({ error: 'Todos os campos são obrigatórios.' });
    }

    if (role !== 'manager' && role !== 'member') {
        return res.status(400).json({ error: 'Função inválida. Use "manager" ou "member".' });
    }

    const users = readUsers();
    
    if (users.find(u => u.username === username)) {
        return res.status(400).json({ error: 'Nome de usuário já existe.' });
    }

    const newUser = {
        id: uuidv4(),
        username,
        password: bcrypt.hashSync(password, 10),
        name,
        role,
        createdAt: new Date().toISOString()
    };

    users.push(newUser);
    writeUsers(users);

    res.status(201).json({
        id: newUser.id,
        username: newUser.username,
        name: newUser.name,
        role: newUser.role
    });
});

// Atualizar usuário (apenas gerente)
app.put('/api/users/:id', authenticateToken, requireManager, (req, res) => {
    const { id } = req.params;
    const { name, role, password } = req.body;

    const users = readUsers();
    const userIndex = users.findIndex(u => u.id === id);

    if (userIndex === -1) {
        return res.status(404).json({ error: 'Usuário não encontrado.' });
    }

    // Não permitir remover o próprio usuário admin se for o último gerente
    if (users[userIndex].username === 'admin' && role !== 'manager') {
        const managers = users.filter(u => u.role === 'manager');
        if (managers.length === 1) {
            return res.status(400).json({ error: 'Não é possível remover a função de gerente do último administrador.' });
        }
    }

    users[userIndex].name = name || users[userIndex].name;
    users[userIndex].role = role || users[userIndex].role;
    
    if (password) {
        users[userIndex].password = bcrypt.hashSync(password, 10);
    }

    writeUsers(users);

    res.json({
        id: users[userIndex].id,
        username: users[userIndex].username,
        name: users[userIndex].name,
        role: users[userIndex].role
    });
});

// Deletar usuário (apenas gerente)
app.delete('/api/users/:id', authenticateToken, requireManager, (req, res) => {
    const { id } = req.params;

    const users = readUsers();
    const userIndex = users.findIndex(u => u.id === id);

    if (userIndex === -1) {
        return res.status(404).json({ error: 'Usuário não encontrado.' });
    }

    // Não permitir deletar o próprio usuário se for o último gerente
    if (users[userIndex].username === 'admin') {
        const managers = users.filter(u => u.role === 'manager');
        if (managers.length === 1) {
            return res.status(400).json({ error: 'Não é possível deletar o último administrador do sistema.' });
        }
    }

    // Remover tarefas atribuídas a este usuário
    const tasks = readTasks();
    const updatedTasks = tasks.filter(t => t.assignedTo !== id);
    writeTasks(updatedTasks);

    users.splice(userIndex, 1);
    writeUsers(users);

    res.json({ message: 'Usuário removido com sucesso.' });
});

app.get('/api/tasks', authenticateToken, (req, res) => {
    const tasks = readTasks();
    const users = readUsers();
    
    // Adicionar nome do responsável às tarefas
    const tasksWithNames = tasks.map(task => {
        const assignedUser = users.find(u => u.id === task.assignedTo);
        const creatorUser = users.find(u => u.id === task.createdBy);
        return {
            ...task,
            assignedToName: assignedUser ? assignedUser.name : 'Usuário removido',
            createdByName: creatorUser ? creatorUser.name : 'Sistema'
        };
    });

    if (req.user.role === 'manager') {
        res.json(tasksWithNames);
    } else {
        // Membros veem apenas tarefas atribuídas a eles ou criadas por eles
        const myTasks = tasksWithNames.filter(t => 
            t.assignedTo === req.user.id || t.createdBy === req.user.id
        );
        res.json(myTasks);
    }
});

// Criar tarefa
app.post('/api/tasks', authenticateToken, (req, res) => {
    const { title, description, priority, assignedTo, dueDate } = req.body;

    if (!title) {
        return res.status(400).json({ error: 'Título é obrigatório.' });
    }

    // Se não especificar assignedTo, atribui a si mesmo
    const finalAssignedTo = assignedTo || req.user.id;

    // Membros só podem criar tarefas para si mesmos
    if (req.user.role !== 'manager' && finalAssignedTo !== req.user.id) {
        return res.status(403).json({ error: 'Membros só podem criar tarefas para si mesmos.' });
    }

    // Verificar se o usuário atribuído existe
    const users = readUsers();
    if (!users.find(u => u.id === finalAssignedTo)) {
        return res.status(400).json({ error: 'Usuário atribuído não encontrado.' });
    }

    const newTask = {
        id: uuidv4(),
        title,
        description: description || '',
        priority: priority || 'medium', // low, medium, high
        status: 'pending', // pending, in_progress, completed
        assignedTo: finalAssignedTo,
        createdBy: req.user.id,
        dueDate: dueDate || null,
        createdAt: new Date().toISOString(),
        updatedAt: new Date().toISOString()
    };

    const tasks = readTasks();
    tasks.push(newTask);
    writeTasks(tasks);

    // Retornar com nomes
    const assignedUser = users.find(u => u.id === finalAssignedTo);
    res.status(201).json({
        ...newTask,
        assignedToName: assignedUser ? assignedUser.name : 'Desconhecido',
        createdByName: req.user.name
    });
});

// Atualizar tarefa (status, edição completa para gerente)
app.put('/api/tasks/:id', authenticateToken, (req, res) => {
    const { id } = req.params;
    const { title, description, priority, status, assignedTo, dueDate } = req.body;

    const tasks = readTasks();
    const taskIndex = tasks.findIndex(t => t.id === id);

    if (taskIndex === -1) {
        return res.status(404).json({ error: 'Tarefa não encontrada.' });
    }

    const task = tasks[taskIndex];

    // Verificar permissões
    const isManager = req.user.role === 'manager';
    const isOwner = task.createdBy === req.user.id;
    const isAssigned = task.assignedTo === req.user.id;

    if (!isManager && !isOwner && !isAssigned) {
        return res.status(403).json({ error: 'Você não tem permissão para editar esta tarefa.' });
    }

    // Membros só podem alterar o status, não podem reatribuir ou editar detalhes de tarefas de outros
    if (!isManager && !isOwner) {
        // Se for apenas o assigned (não criador), só pode mudar status
        if (title || description || assignedTo) {
            return res.status(403).json({ error: 'Você só pode alterar o status desta tarefa.' });
        }
    }

    // Atualizar campos
    if (title !== undefined) tasks[taskIndex].title = title;
    if (description !== undefined) tasks[taskIndex].description = description;
    if (priority !== undefined) tasks[taskIndex].priority = priority;
    if (status !== undefined) tasks[taskIndex].status = status;
    if (dueDate !== undefined) tasks[taskIndex].dueDate = dueDate;
    
    // Apenas gerente pode reatribuir
    if (assignedTo !== undefined && isManager) {
        const users = readUsers();
        if (!users.find(u => u.id === assignedTo)) {
            return res.status(400).json({ error: 'Usuário atribuído não encontrado.' });
        }
        tasks[taskIndex].assignedTo = assignedTo;
    }

    tasks[taskIndex].updatedAt = new Date().toISOString();

    writeTasks(tasks);

    // Retornar com nomes
    const users = readUsers();
    const assignedUser = users.find(u => u.id === tasks[taskIndex].assignedTo);
    const creatorUser = users.find(u => u.id === tasks[taskIndex].createdBy);

    res.json({
        ...tasks[taskIndex],
        assignedToName: assignedUser ? assignedUser.name : 'Desconhecido',
        createdByName: creatorUser ? creatorUser.name : 'Sistema'
    });
});

// Deletar tarefa
app.delete('/api/tasks/:id', authenticateToken, (req, res) => {
    const { id } = req.params;

    const tasks = readTasks();
    const taskIndex = tasks.findIndex(t => t.id === id);

    if (taskIndex === -1) {
        return res.status(404).json({ error: 'Tarefa não encontrada.' });
    }

    const task = tasks[taskIndex];

    // Apenas gerente ou criador pode deletar
    if (req.user.role !== 'manager' && task.createdBy !== req.user.id) {
        return res.status(403).json({ error: 'Você não tem permissão para excluir esta tarefa.' });
    }

    tasks.splice(taskIndex, 1);
    writeTasks(tasks);

    res.json({ message: 'Tarefa removida com sucesso.' });
});

            e.target.classList.remove('active');
        }
    });

// Autenticação
async function validateToken() {
    try {
        const response = await fetch('/api/me', {
            headers: { 'Authorization': `Bearer ${token}` }
        });

        if (response.ok) {
            currentUser = await response.json();
            showDashboard();
            loadInitialData();
        } else {
            localStorage.removeItem('token');
            token = null;
            showLoginScreen();
        }
    } catch (error) {
        console.error('Erro ao validar token:', error);
        showLoginScreen();
    }
}

async function handleLogin(e) {
    e.preventDefault();
    const username = document.getElementById('login-username').value;
    const password = document.getElementById('login-password').value;
    const errorDiv = document.getElementById('login-error');

    try {
        const response = await fetch('/api/login', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ username, password })
        });

        const data = await response.json();

        if (response.ok) {
            token = data.token;
            currentUser = data.user;
            localStorage.setItem('token', token);
            errorDiv.classList.add('hidden');
            showDashboard();
            loadInitialData();
        } else {
            errorDiv.textContent = data.error || 'Erro ao fazer login';
            errorDiv.classList.remove('hidden');
        }
    } catch (error) {
        errorDiv.textContent = 'Erro de conexão. Tente novamente.';
        errorDiv.classList.remove('hidden');
    }
}

function handleLogout() {
    localStorage.removeItem('token');
    token = null;
    currentUser = null;
    showLoginScreen();
    document.getElementById('login-form').reset();
}

// Navegação
function showLoginScreen() {
    document.getElementById('login-screen').classList.add('active');
    document.getElementById('dashboard-screen').classList.remove('active');
}

function showDashboard() {
    document.getElementById('login-screen').classList.remove('active');
    document.getElementById('dashboard-screen').classList.add('active');
    
    // Atualizar UI com dados do usuário
    document.getElementById('user-name-display').textContent = currentUser.name;
    const roleBadge = document.getElementById('user-role-badge');
    roleBadge.textContent = currentUser.role === 'manager' ? 'Gerente' : 'Membro';
    roleBadge.className = `badge ${currentUser.role}`;

    // Mostrar/ocultar tabs baseado na role
    const isManager = currentUser.role === 'manager';
    document.getElementById('tab-all-tasks').style.display = isManager ? 'block' : 'none';
    document.getElementById('tab-team').style.display = isManager ? 'block' : 'none';
}

function switchTab(tabName) {
    // Atualizar botões
    document.querySelectorAll('.tab-btn').forEach(btn => {
        btn.classList.toggle('active', btn.dataset.tab === tabName);
    });

    // Atualizar conteúdo
    document.querySelectorAll('.tab-content').forEach(content => {
        content.classList.toggle('active', content.id === `tab-${tabName}`);
    });

    // Carregar dados específicos
    if (tabName === 'tasks') loadTasks();
    if (tabName === 'all-tasks') loadAllTasks();
    if (tabName === 'team') loadUsers();
}

// Carregamento de Dados
async function loadInitialData() {
    await loadTasks();
    if (currentUser.role === 'manager') {
        await loadUsers(); // Necessário para o select de atribuição
        populateUserSelects();
    }
}

async function loadTasks() {
    try {
        const response = await fetch('/api/tasks', {
            headers: { 'Authorization': `Bearer ${token}` }
        });

        if (response.ok) {
            allTasks = await response.json();
            renderTasks('tasks-list', allTasks);
        }
    } catch (error) {
        console.error('Erro ao carregar tarefas:', error);
        showToast('Erro ao carregar tarefas', 'error');
    }
}

async function loadAllTasks() {
    try {
        const response = await fetch('/api/tasks', {
            headers: { 'Authorization': `Bearer ${token}` }
        });

        if (response.ok) {
            allTasks = await response.json();
            renderTasks('all-tasks-list', allTasks);
        }
    } catch (error) {
        console.error('Erro ao carregar todas as tarefas:', error);
    }
}

async function loadUsers() {
    try {
        const response = await fetch('/api/users', {
            headers: { 'Authorization': `Bearer ${token}` }
        });

        if (response.ok) {
            allUsers = await response.json();
            renderUsersTable();
            populateUserSelects();
        }
    } catch (error) {
        console.error('Erro ao carregar usuários:', error);
    }
}

// Renderização
function renderTasks(containerId, tasks) {
    const container = document.getElementById(containerId);
    const statusFilter = document.getElementById(containerId === 'tasks-list' ? 'filter-status' : 'filter-status-all').value;
    const priorityFilter = document.getElementById('filter-priority')?.value || '';
    const userFilter = document.getElementById('filter-user')?.value || '';

    let filtered = tasks;

    if (statusFilter) {
        filtered = filtered.filter(t => t.status === statusFilter);
    }
    if (priorityFilter && containerId === 'tasks-list') {
        filtered = filtered.filter(t => t.priority === priorityFilter);
    }
    if (userFilter && containerId === 'all-tasks-list') {
        filtered = filtered.filter(t => t.assignedTo === userFilter);
    }

    if (filtered.length === 0) {
        container.innerHTML = '<div class="loading">Nenhuma tarefa encontrada.</div>';
        return;
    }

    container.innerHTML = filtered.map(task => `
        <div class="task-card priority-${task.priority} status-${task.status}">
            <div class="task-header">
                <div>
                    <div class="task-title">${escapeHtml(task.title)}</div>
                    <div class="task-meta">
                        <span class="task-badge status-${task.status}">${getStatusLabel(task.status)}</span>
                        <span class="task-badge priority-${task.priority}">${getPriorityLabel(task.priority)}</span>
                    </div>
                </div>
                <div class="task-actions">
                    ${canEditTask(task) ? `<button class="btn-icon" onclick="openTaskModal('${task.id}')" title="Editar">✏️</button>` : ''}
                    ${canDeleteTask(task) ? `<button class="btn-icon" onclick="openConfirmModal('${task.id}', 'task')" title="Excluir">🗑️</button>` : ''}
                </div>
            </div>
            
            ${task.description ? `<div class="task-description">${escapeHtml(task.description)}</div>` : ''}
            
            <div class="task-footer">
                <div class="task-assignee">
                    <span>👤 ${escapeHtml(task.assignedToName)}</span>
                </div>
                ${task.dueDate ? `<div class="task-date ${isOverdue(task.dueDate) ? 'overdue' : ''}">📅 ${formatDate(task.dueDate)}</div>` : ''}
            </div>
            
            ${task.status !== 'completed' && canChangeStatus(task) ? `
                <div style="margin-top: 0.75rem; padding-top: 0.75rem; border-top: 1px solid var(--border-color);">
                    <select onchange="updateTaskStatus('${task.id}', this.value)" style="width: 100%; padding: 0.375rem; border-radius: 0.25rem; border: 1px solid var(--border-color);">
                        <option value="">Alterar status...</option>
                        <option value="pending" ${task.status === 'pending' ? 'selected' : ''}>Pendente</option>
                        <option value="in_progress" ${task.status === 'in_progress' ? 'selected' : ''}>Em Andamento</option>
                        <option value="completed" ${task.status === 'completed' ? 'selected' : ''}>Concluída</option>
                    </select>
                </div>
            ` : ''}
        </div>
    `).join('');
}

function renderUsersTable() {
    const tbody = document.getElementById('users-table-body');
    
    if (allUsers.length === 0) {
        tbody.innerHTML = '<tr><td colspan="5" class="loading">Nenhum usuário encontrado.</td></tr>';
        return;
    }

    tbody.innerHTML = allUsers.map(user => `
        <tr>
            <td>${escapeHtml(user.name)}</td>
            <td>${escapeHtml(user.username)}</td>
            <td><span class="badge ${user.role}">${user.role === 'manager' ? 'Gerente' : 'Membro'}</span></td>
            <td>${formatDate(user.createdAt)}</td>
            <td>
                <button class="btn-icon" onclick="openUserModal('${user.id}')" title="Editar">✏️</button>
                ${user.username !== 'admin' ? `<button class="btn-icon" onclick="openConfirmModal('${user.id}', 'user')" title="Excluir">🗑️</button>` : ''}
            </td>
        </tr>
    `).join('');
}

function populateUserSelects() {
    const selects = [
        document.getElementById('task-assigned-to'),
        document.getElementById('filter-user')
    ];

    selects.forEach(select => {
        if (!select) return;
        
        const currentValue = select.value;
        const isFilter = select.id === 'filter-user';
        
        // Manter a primeira opção se for filtro
        const firstOption = isFilter ? select.options[0] : null;
        
        select.innerHTML = '';
        
        if (isFilter) {
            select.appendChild(firstOption);
        } else {
            // No modal de tarefa, adicionar opção "Eu mesmo"
            const selfOption = document.createElement('option');
            selfOption.value = currentUser.id;
            selfOption.textContent = `Eu mesmo (${currentUser.name})`;
            select.appendChild(selfOption);
        }

        allUsers.forEach(user => {
            if (isFilter || user.id !== currentUser.id) {
                const option = document.createElement('option');
                option.value = user.id;
                option.textContent = user.name;
                select.appendChild(option);
            }
        });

        if (currentValue) select.value = currentValue;
    });
}

// Modais - Tarefa
function openTaskModal(taskId = null) {
    const modal = document.getElementById('task-modal');
    const form = document.getElementById('task-form');
    const title = document.getElementById('task-modal-title');
    const statusGroup = document.getElementById('task-status-group');
    const assigneeGroup = document.getElementById('task-assignee-group');
    
    form.reset();
    document.getElementById('task-id').value = '';
    
    // Configurar visibilidade baseada na role
    const isManager = currentUser.role === 'manager';
    assigneeGroup.style.display = isManager ? 'block' : 'none';
    
    if (taskId) {
        const task = allTasks.find(t => t.id === taskId);
        if (task) {
            title.textContent = 'Editar Tarefa';
            document.getElementById('task-id').value = task.id;
            document.getElementById('task-title').value = task.title;
            document.getElementById('task-description').value = task.description || '';
            document.getElementById('task-priority').value = task.priority;
            document.getElementById('task-due-date').value = task.dueDate || '';
            document.getElementById('task-status').value = task.status;
            
            if (isManager) {
                document.getElementById('task-assigned-to').value = task.assignedTo;
            }
            
            statusGroup.style.display = 'block';
        }
    } else {
        title.textContent = 'Nova Tarefa';
        statusGroup.style.display = 'none';
        
        if (isManager) {
            populateUserSelects(); // Recarregar para garantir
        }
    }
    
    modal.classList.add('active');
}

function closeTaskModal() {
    document.getElementById('task-modal').classList.remove('active');
}

async function handleTaskSubmit(e) {
    e.preventDefault();
    
    const taskId = document.getElementById('task-id').value;
    const isManager = currentUser.role === 'manager';
    
    const taskData = {
        title: document.getElementById('task-title').value,
        description: document.getElementById('task-description').value,
        priority: document.getElementById('task-priority').value,
        dueDate: document.getElementById('task-due-date').value || null
    };

    if (isManager) {
        taskData.assignedTo = document.getElementById('task-assigned-to').value;
    } else {
        taskData.assignedTo = currentUser.id;
    }

    if (taskId) {
        taskData.status = document.getElementById('task-status').value;
    }

    try {
        const url = taskId ? `/api/tasks/${taskId}` : '/api/tasks';
        const method = taskId ? 'PUT' : 'POST';
        
        const response = await fetch(url, {
            method,
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${token}`
            },
            body: JSON.stringify(taskData)
        });

        if (response.ok) {
            showToast(taskId ? 'Tarefa atualizada!' : 'Tarefa criada!', 'success');
            closeTaskModal();
            loadTasks();
            if (document.getElementById('tab-all-tasks').classList.contains('active')) {
                loadAllTasks();
            }
        } else {
            const data = await response.json();
            showToast(data.error || 'Erro ao salvar tarefa', 'error');
        }
    } catch (error) {
        showToast('Erro de conexão', 'error');
    }
}

async function updateTaskStatus(taskId, newStatus) {
    if (!newStatus) return;
    
    try {
        const response = await fetch(`/api/tasks/${taskId}`, {
            method: 'PUT',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${token}`
            },
            body: JSON.stringify({ status: newStatus })
        });

        if (response.ok) {
            showToast('Status atualizado!', 'success');
            loadTasks();
            if (document.getElementById('tab-all-tasks').classList.contains('active')) {
                loadAllTasks();
            }
        } else {
            showToast('Erro ao atualizar status', 'error');
            loadTasks(); // Recarregar para reverter o select
        }
    } catch (error) {
        showToast('Erro de conexão', 'error');
    }
}

// Modais - Usuário
function openUserModal(userId = null) {
    const modal = document.getElementById('user-modal');
    const form = document.getElementById('user-form');
    const title = document.getElementById('user-modal-title');
    const passwordHint = document.getElementById('password-hint');
    
    form.reset();
    document.getElementById('user-id').value = '';
    
    if (userId) {
        const user = allUsers.find(u => u.id === userId);
        if (user) {
            title.textContent = 'Editar Membro';
            document.getElementById('user-id').value = user.id;
            document.getElementById('user-name').value = user.name;
            document.getElementById('user-username').value = user.username;
            document.getElementById('user-username').disabled = true; // Não permitir mudar username
            document.getElementById('user-role').value = user.role;
            document.getElementById('user-password').required = false;
            passwordHint.textContent = '(deixe em branco para manter)';
        }
    } else {
        title.textContent = 'Novo Membro';
        document.getElementById('user-username').disabled = false;
        document.getElementById('user-password').required = true;
        passwordHint.textContent = '*';
    }
    
    modal.classList.add('active');
}

function closeUserModal() {
    document.getElementById('user-modal').classList.remove('active');
}

async function handleUserSubmit(e) {
    e.preventDefault();
    
    const userId = document.getElementById('user-id').value;
    const password = document.getElementById('user-password').value;
    
    const userData = {
        name: document.getElementById('user-name').value,
        role: document.getElementById('user-role').value
    };

    if (!userId) {
        userData.username = document.getElementById('user-username').value;
        userData.password = password;
    } else if (password) {
        userData.password = password;
    }

    try {
        const url = userId ? `/api/users/${userId}` : '/api/users';
        const method = userId ? 'PUT' : 'POST';
        
        const response = await fetch(url, {
            method,
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${token}`
            },
            body: JSON.stringify(userData)
        });

        if (response.ok) {
            showToast(userId ? 'Usuário atualizado!' : 'Usuário criado!', 'success');
            closeUserModal();
            loadUsers();
        } else {
            const data = await response.json();
            showToast(data.error || 'Erro ao salvar usuário', 'error');
        }
    } catch (error) {
        showToast('Erro de conexão', 'error');
    }
}

// Modal de Confirmação
function openConfirmModal(id, type) {
    currentDeleteId = id;
    currentDeleteType = type;
    
    const message = type === 'task' 
        ? 'Tem certeza que deseja excluir esta tarefa? Esta ação não pode ser desfeita.'
        : 'Tem certeza que deseja excluir este usuário? Todas as tarefas atribuídas a ele serão removidas.';
    
    document.getElementById('confirm-message').textContent = message;
    document.getElementById('confirm-modal').classList.add('active');
}

function closeConfirmModal() {
    document.getElementById('confirm-modal').classList.remove('active');
    currentDeleteId = null;
    currentDeleteType = null;
}

async function confirmDelete() {
    if (!currentDeleteId || !currentDeleteType) return;

    try {
        const url = currentDeleteType === 'task' 
            ? `/api/tasks/${currentDeleteId}`
            : `/api/users/${currentDeleteId}`;
        
        const response = await fetch(url, {
            method: 'DELETE',
            headers: { 'Authorization': `Bearer ${token}` }
        });

        if (response.ok) {
            showToast('Item excluído com sucesso!', 'success');
            closeConfirmModal();
            
            if (currentDeleteType === 'task') {
                loadTasks();
                if (document.getElementById('tab-all-tasks').classList.contains('active')) {
                    loadAllTasks();
                }
            } else {
                loadUsers();
            }
        } else {
            const data = await response.json();
            showToast(data.error || 'Erro ao excluir', 'error');
        }
    } catch (error) {
        showToast('Erro de conexão', 'error');
    }
}

// Permissões
function canEditTask(task) {
    if (currentUser.role === 'manager') return true;
    if (task.createdBy === currentUser.id) return true;
    if (task.assignedTo === currentUser.id) return true; // Pode editar apenas status, mas o botão abre o modal
    return false;
}

function canDeleteTask(task) {
    if (currentUser.role === 'manager') return true;
    if (task.createdBy === currentUser.id) return true;
    return false;
}

function canChangeStatus(task) {
    if (currentUser.role === 'manager') return true;
    if (task.assignedTo === currentUser.id) return true;
    if (task.createdBy === currentUser.id) return true;
    return false;
}

// Utilitários
function escapeHtml(text) {
    if (!text) return '';
    const div = document.createElement('div');
    div.textContent = text;
    return div.innerHTML;
}

function formatDate(dateString) {
    if (!dateString) return '';
    const date = new Date(dateString);
    return date.toLocaleDateString('pt-BR');
}

function isOverdue(dateString) {
    if (!dateString) return false;
    const today = new Date();
    today.setHours(0, 0, 0, 0);
    const due = new Date(dateString);
    return due < today;
}

function getStatusLabel(status) {
    const labels = {
        'pending': 'Pendente',
        'in_progress': 'Em Andamento',
        'completed': 'Concluída'
    };
    return labels[status] || status;
}

function getPriorityLabel(priority) {
    const labels = {
        'low': 'Baixa',
        'medium': 'Média',
        'high': 'Alta'
    };
    return labels[priority] || priority;
}

function showToast(message, type = 'success') {
    const container = document.getElementById('toast-container');
    const toast = document.createElement('div');
    toast.className = `toast ${type}`;
    
    const icon = type === 'success' ? '✅' : type === 'error' ? '❌' : 'ℹ️';
    
    toast.innerHTML = `
        <span>${icon}</span>
        <span>${message}</span>
    `;
    
    container.appendChild(toast);
    
    setTimeout(() => {
        toast.style.animation = 'slideIn 0.3s ease-out reverse';
        setTimeout(() => toast.remove(), 300);
    }, 3000);
}
