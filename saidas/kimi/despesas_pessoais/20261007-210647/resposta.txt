# 💰 Controle de Despesas Pessoais

## 📋 O que é
Um site para você controlar seus gastos pessoais. Cada pessoa tem sua conta, registra seus gastos e vê quanto gastou no mês. O administrador gerencia categorias, usuários e vê relatórios gerais.

## 🔑 Primeiro Acesso (Administrador)

- **Email:** admin@admin.com
- **Senha:** admin123

## ▶️ Como rodar

```bash
# 1. Baixar/instalar dependências
npm install

# 2. Rodar o servidor
npm start
```

Abra no navegador: **http://localhost:3000**

## 🚀 Colocar na internet (Render.com - grátis)

1. Crie uma conta em https://render.com
2. Crie um repositório no GitHub com esses arquivos
3. No Render, clique em **New > Web Service**
4. Conecte seu repositório GitHub
5. Configure:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
6. Clique em **Deploy**

Pronto! Seu site estará no ar com um link público.

## 👤 Como usar

### Para usuários normais:
1. Clique em **"Cadastrar"** na tela inicial
2. Preencha nome, email e senha
3. Faça login
4. Registre seus gastos
5. Veja o resumo mensal

### Para administrador:
1. Entre com admin@admin.com / admin123
2. Cadastre categorias de gasto
3. Gerencie usuários
4. Veja relatórios gerais

## 🗄️ Banco de dados
Os dados ficam salvos no arquivo `despesas.db` (SQLite) - tudo dentro do próprio site, sem serviços externos.

## 📦 Tecnologias
- **Backend:** Node.js + Express
- **Banco:** SQLite
- **Frontend:** HTML + CSS + JavaScript
- **Autenticação:** JWT + bcrypt
