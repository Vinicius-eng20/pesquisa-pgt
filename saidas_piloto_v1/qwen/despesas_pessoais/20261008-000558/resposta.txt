O site precisa funcionar de verdade na internet com salvamento real e contas de usuário separadas. Isso exige um **servidor + banco de dados** (impossível fazer só com um arquivo HTML — navegador não guarda dados de outras pessoas nem protege senhas).

Usei **Node.js + Supabase (banco gratuito na nuvem)** — é "dentro do próprio site" (não usa OAuth, Facebook, Stripe, etc.), roda em hospedagem gratuita, e cada pessoa entra com seu usuário/senha e só vê os próprios gastos.

**Importante:** o banco é um arquivo de configuração com um link (URL + chave). Você pega esse link no Supabase (grátis, 2 min) e cola nele. Depois, suba o projeto num serviço gratuito (Cloudflare Workers — 5 min, eu deixo os passos) e fique no ar.

-- RODE ESTE BLOCO uma única vez na aba SQL Editor do Supabase (veja README).
-- Cria todas as tabelas e regras de segurança.

create table public.users (
  id uuid primary key default gen_random_uuid(),
  username text unique not null,
  email text unique not null,
  password_hash text not null,
  is_admin boolean not null default false,
  is_active boolean not null default true,
  created_at timestamptz not null default now()
);

create table public.categories (
  id uuid primary key default gen_random_uuid(),
  name text unique not null,
  color text not null default '#64748B',
  is_active boolean not null default true,
  created_at timestamptz not null default now()
);

create table public.expenses (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references public.users(id) on delete cascade,
  category_id uuid not null references public.categories(id) on delete restrict,
  description text not null,
  amount_cents integer not null check (amount_cents >= 0),
  spent_on date not null default current_date,
  created_at timestamptz not null default now()
);

create index expenses_user_spent_idx on public.expenses (user_id, spent_on);
create index expenses_category_idx on public.expenses (category_id);

-- Permite apenas leitura para quem se autenticou; escrita é feita pelo servidor.
alter table public.users enable row level security;
alter table public.categories enable row level security;
alter table public.expenses enable row level security;

create policy "read users" on public.users for select using (auth.role() = 'authenticated');
create policy "read categories" on public.categories for select using (auth.role() = 'authenticated');
create policy "read own expenses" on public.expenses for select using (auth.uid() = user_id);

function readBody(req) {
  return new Promise((resolve, reject) => {
    let data = '';
    req.on('data', (c) => {
      data += c;
      if (data.length > 1e6) { reject(new Error('muito grande')); req.destroy(); }
    });
    req.on('end', () => {
      if (!data) return resolve({});
      try { resolve(JSON.parse(data)); } catch { reject(new Error('json inválido')); }
    });
    req.on('error', reject);
  });
}

function parseToken(tok) {
  if (!tok) return null;
  const [aid, payload] = tok.split('.');
  if (!aid || !payload) return null;
  const exp = Number(payload.split('.')[0]);
  if (!exp || Date.now() > exp) return null;
  return { id: aid, exp };
}

function setCookie(res, token, active) {
  res.setHeader('Set-Cookie', cookie.serialize(COOKIE, token, {
    httpOnly: true,
    sameSite: 'strict',
    secure: process.env.NODE_ENV === 'production',
    path: '/',
    maxAge: active ? 60 * 60 * 24 * 30 : 0
  }));
}

  }));
}

function toCents(s) {
  if (s === undefined || s === null) return null;
  let t = String(s).trim().replace(/[R$\s]/g, '');
  if (t === '') return null;
  if (t.includes(',')) t = t.replace(/\./g, '').replace(',', '.');
  const n = Number(t);
  if (!isFinite(n) || n < 0) return null;
  return Math.round(n * 100);
}
function safeDate(s) {
  if (!s) return null;

  if (isNaN(d.getTime())) return null;

function matchPath(pattern, urlPath) {
  const a = pattern.split('/').filter(Boolean);
  const b = urlPath.split('/').filter(Boolean);
  if (a.length !== b.length) return null;
  const params = {};
  for (let i = 0; i < a.length; i++) {
    if (a[i].startsWith(':')) params[a[i].slice(1)] = decodeURIComponent(b[i]);
    else if (a[i] !== b[i]) return null;
  }
  return params;
}

function makeHandler() {
  return async function handler(req, res) {
    try {
      const url = new URL(req.url, 'http://localhost');
      const p = url.pathname;

      if (p.startsWith('/api/')) {
        for (const r of routes) {
          if (r.method !== req.method) continue;
          const params = matchPath(r.path, p);
          if (params === null) continue;
          req.params = params;
          return await r.handler(req, res);
        }
        return bad(req, res, 404, 'Rota não encontrada.');
      }

      let filePath;
      if (p === '/' ) filePath = path.join(PUBLIC_DIR, 'index.html');
      else {
        const clean = p.split('?')[0];
        filePath = path.normalize(path.join(PUBLIC_DIR, clean));
        if (!filePath.startsWith(PUBLIC_DIR)) { res.writeHead(403); res.end(); return; }
      }
      if (!fs.existsSync(filePath) || !fs.statSync(filePath).isFile()) {
        sendFile(res, path.join(PUBLIC_DIR, 'index.html'), 'text/html; charset=utf-8');
        return;
      }
      sendFile(res, filePath, MIME[path.extname(filePath).toLowerCase()] || 'application/octet-stream');
    } catch (e) {
      console.error(e);
      try { bad(req, res, 500, 'Erro interno no servidor.'); } catch {}
    }
  };
}

      toast(register ? 'Conta criada! Bem-vindo(a) 🎉' : 'Bem-vindo(a) de volta');
      await boot();
    } catch (err) {
      msg.textContent = err.message;
      msg.classList.remove('hidden');
    }
  });

  $('logout-btn').addEventListener('click', async () => {
    try { await api('/api/logout', { method: 'POST' }); } catch {}
    state.user = null;
    state.expenses = [];
    state.categories = [];
    showAuth();
  });

  // ---------- navegação ----------
  $('tab-me').addEventListener('click', () => switchView('me'));
  $('tab-admin').addEventListener('click', () => switchView('admin'));
  function switchView(v) {
    if (v === 'admin' && !state.user.is_admin) v = 'me';
    state.view = v;
    $('tab-me').classList.toggle('active', v === 'me');
    $('tab-admin').classList.toggle('active', v === 'admin');
    $('view-me').classList.toggle('hidden', v !== 'me');
    $('view-admin').classList.toggle('hidden', v !== 'admin');
    if (v === 'admin') loadAdmin();
  }

  // ---------- categorias ----------
  function populateCategorySelects() {
    const sel = $('exp-category');
    sel.innerHTML = '<option value="">Escolha…</option>';
    state.categories.forEach(c => {
      const o = document.createElement('option');
      o.value = c.id; o.textContent = c.name;
      sel.appendChild(o);
    });
    const fsel = $('filter-category');
    const prev = fsel.value;
    fsel.innerHTML = '<option value="">Todas as categorias</option>';
    const names = {};
    state.expenses.forEach(e => { if (e.category) names[e.category.name] = 1; });
    Object.keys(names).sort().forEach(n => {
      const o = document.createElement('option'); o.value = n; o.textContent = n; fsel.appendChild(o);
    });
    if ([...fsel.options].some(o => o.value === prev)) fsel.value = prev;
  }

  function populateMonthSelect() {
    const sel = $('filter-month');
    const all = new Set();
    state.expenses.forEach(e => all.add(ymOf(e.spent_on)));
    all.add(currentYM());
    const yms = [...all].sort().reverse();
    const prev = sel.value;
    sel.innerHTML = '';
    const allOpt = document.createElement('option');
    allOpt.value = ''; allOpt.textContent = 'Todos os meses';
    sel.appendChild(allOpt);
    yms.forEach(ym => {
      const o = document.createElement('option'); o.value = ym; o.textContent = monthLabel(ym); sel.appendChild(o);
    });
    if ([...sel.options].some(o => o.value === prev)) sel.value = prev;
  }

  // ---------- render: meus gastos ----------
  function statMonth() {
    const ym = currentYM();
    const sum = state.expenses.filter(e => ymOf(e.spent_on) === ym).reduce((s, e) => s + e.amount_cents, 0);
    return sum;
  }
  function renderMe() {
    $('me-month-label').textContent = monthLabel(currentYM());
    $('stat-month').textContent = brl(statMonth());
    $('stat-month-hint').textContent = 'só este mês';
    const total = state.expenses.reduce((s, e) => s + e.amount_cents, 0);
    $('stat-total').textContent = brl(total);
    $('stat-total-hint').textContent = 'desde o início';
    $('stat-count').textContent = state.expenses.length;

    populateMonthSelect();
    populateCategorySelects();
    renderList();
  }

  function filteredExpenses() {
    return state.expenses.filter(e => {
      if (state.filterMonth && ymOf(e.spent_on) !== state.filterMonth) return false;
      if (state.filterCategory && e.category.name !== state.filterCategory) return false;
      return true;
    });
  }

  function renderList() {
    const list = filteredExpenses();
    const groups = $('expense-groups');
    groups.innerHTML = '';
    const noData = $('no-data');
    if (!list.length) {
      noData.classList.remove('hidden');
      return;
    }
    noData.classList.add('hidden');

    const byDate = {};
    list.forEach(e => {
      (byDate[e.spent_on] = byDate[e.spent_on] || []).push(e);
    });
    const dates = Object.keys(byDate).sort((a, b) => (a < b ? 1 : -1));
    dates.forEach(date => {
      const items = byDate[date];
      const total = items.reduce((s, e) => s + e.amount_cents, 0);
      const g = document.createElement('div');
      g.className = 'expense-group';

      const head = document.createElement('div');
      head.className = 'group-head';
      const dl = document.createElement('div');
      dl.innerHTML = `<span class="group-date">${dateLabel(date)}</span>`;
      const gt = document.createElement('span');
      gt.className = 'group-total'; gt.textContent = brl(total);
      head.appendChild(dl); head.appendChild(gt);
      g.appendChild(head);

      items.forEach(e => {
        const row = document.createElement('div');
        row.className = 'expense-item';
        const chip = document.createElement('span');
        chip.className = 'cat-chip';
        chip.innerHTML =
          `<span class="cat-dot" style="background:${e.category.color}"></span>` +
          `<span class="exp-desc">${escapeHtml(e.description)}</span>` +
          `<span class="exp-cat-name">${escapeHtml(e.category.name)}</span>`;
        const amt = document.createElement('span');
        amt.className = 'exp-amount'; amt.textContent = brl(e.amount_cents);
        const del = document.createElement('button');
        del.className = 'exp-del'; del.type = 'button'; del.title = 'Excluir'; del.textContent = '✕';
        del.addEventListener('click', () => deleteExpense(e.id));
        row.appendChild(chip); row.appendChild(amt); row.appendChild(del);
        g.appendChild(row);
      });
      groups.appendChild(g);
    });
  }
  function escapeHtml(s) {
    return String(s).replace(/[&<>"']/g, c => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));
  }

  // ---------- adicionar / excluir gasto ----------
  $('exp-date').value = todayISO();
  $('expense-form').addEventListener('submit', async (e) => {
    e.preventDefault();
    const msg = $('expense-message'); msg.textContent = '';
    const btn = e.target.querySelector('button[type=submit]');
    const original = btn.textContent; btn.disabled = true; btn.textContent = 'Salvando…';
    try {
      const payload = {
        description: $('exp-desc').value.trim(),
        amount: $('exp-amount').value.trim(),
        category_id: $('exp-category').value,
        spent_on: $('exp-date').value
      };
      const data = await api('/api/expenses', { method: 'POST', body: payload });
      state.expenses.unshift(data.expense);
      $('exp-desc').value = ''; $('exp-amount').value = ''; $('exp-date').value = todayISO();
      renderMe();
      toast('Gasto registrado!');
    } catch (err) { msg.textContent = err.message; }
    finally { btn.disabled = false; btn.textContent = original; }
  });

  async function deleteExpense(id) {
    try {
      await api('/api/expenses/' + id, { method: 'DELETE' });
      state.expenses = state.expenses.filter(e => e.id !== id);
      renderMe();
      toast('Gasto excluído');
    } catch (err) { toast(err.message, false); }
  }

  $('filter-month').addEventListener('change', (e) => { state.filterMonth = e.target.value; renderList(); });
  $('filter-category').addEventListener('change', (e) => { state.filterCategory = e.target.value; renderList(); });
  $('me-refresh').addEventListener('click', async () => { await loadExpenses(); toast('Atualizado'); });

  // ---------- admin ----------
  async function loadAdmin() {
    try {
      const data = await api('/api/admin/overview');
      $('admin-total').textContent = brl(data.total_cents);
      $('admin-users').textContent = data.active_count;
      $('admin-avg').textContent = brl(data.avg_cents);
      renderUsers(data.users);
    } catch (err) { toast(err.message, false); }
    try { await loadCategories(true); } catch (err) { toast(err.message, false); }
  }

  function renderUsers(users) {
    const tb = $('user-rows'); tb.innerHTML = '';
    users.forEach(u => {
      const tr = document.createElement('tr');
      const statusOn = u.is_active;
      tr.innerHTML =
        `<td class="user-name">${escapeHtml(u.username)}</td>` +
        `<td class="user-total">${brl(u.total_cents)}</td>` +
        `<td><span class="status-pill ${statusOn ? 'status-on' : 'status-off'}">${statusOn ? 'Ativo' : 'Desativado'}</span></td>` +
        `<td></td>`;
      const td = tr.lastElementChild;
      const b = document.createElement('button');
      b.className = 'toggle' + (statusOn ? '' : ' off');
      b.type = 'button';
      b.textContent = statusOn ? 'Desativar' : 'Reativar';
      b.addEventListener('click', () => toggleUser(u, b));
      td.appendChild(b);
      tb.appendChild(tr);
    });
    if (!users.length) {
      const tr = document.createElement('tr');
      tr.innerHTML = '<td colspan="4" style="color:var(--ink-soft);text-align:center;padding:24px">Nenhum usuário ainda.</td>';
      tb.appendChild(tr);
    }
  }

  async function toggleUser(u, btn) {
    btn.disabled = true;
    try {
      const next = !u.is_active;
      const data = await api('/api/admin/users/' + u.id, { method: 'PATCH', body: { is_active: next } });
      u.is_active = data.user.is_active;
      btn.textContent = u.is_active ? 'Desativar' : 'Reativar';
      btn.className = 'toggle' + (u.is_active ? '' : ' off');
      loadAdmin();
      toast(u.is_active ? 'Conta reativada' : 'Conta desativada');
    } catch (err) {
      toast(err.message, false);
      btn.disabled = false;
    }
  }

  async function loadCategories(admin = false) {
    const data = await api('/api/categories');
    state.categories = data.categories;
    if (admin) renderCategories();
    else populateCategorySelects();
  }

  function renderCategories() {
    const list = $('category-list'); list.innerHTML = '';
    // contagem de gastos por categoria (uso os gastos carregados do admin? não carregamos gastos do admin; usamos só nome/estado)
    state.categories.forEach(c => {
      const li = document.createElement('li');
      li.className = 'category-row' + (c.is_active ? '' : ' is-off');
      li.innerHTML =
        `<span class="cat-dot" style="background:${c.color}"></span>` +
        `<span class="cat-name">${escapeHtml(c.name)}</span>` +
        `<button class="toggle ${c.is_active ? '' : 'off'}" type="button">${c.is_active ? 'Ativa' : 'Desativada'}</button>`;
      const b = li.querySelector('button');
      b.addEventListener('click', () => toggleCategory(c, b));
      list.appendChild(li);
    });
    if (!state.categories.length) {
      const li = document.createElement('li');
      li.className = 'empty'; li.style.padding = '16px'; li.textContent = 'Nenhuma categoria ainda.';
      list.appendChild(li);
    }
  }

  async function toggleCategory(c, btn) {
    btn.disabled = true;
    try {
      const next = !c.is_active;
      const data = await api('/api/admin/categories/' + c.id, { method: 'PATCH', body: { is_active: next } });
      c.is_active = data.category.is_active;
      c.name = data.category.name;
      renderCategories();
      await loadCategories(false);
      renderMe();
      toast(c.is_active ? 'Categoria ativada' : 'Categoria desativada');
    } catch (err) {
      toast(err.message, false);
      btn.disabled = false;
    }
  }

  $('category-form').addEventListener('submit', async (e) => {
    e.preventDefault();
    const msg = $('category-message'); msg.textContent = '';
    try {
      await api('/api/admin/categories', {
        method: 'POST',
        body: { name: $('cat-name').value.trim(), color: $('cat-color').value }
      });
      $('cat-name').value = '';
      await loadCategories(true);
      toast('Categoria adicionada');
    } catch (err) { msg.textContent = err.message; }
  });

  // ---------- carga inicial de dados do usuário ----------
  async function loadExpenses() {
    const data = await api('/api/expenses');
    state.expenses = data.expenses;
    renderMe();
  }

  async function boot() {
    showApp();
    try {
      await Promise.all([loadCategories(false), loadExpenses()]);
    } catch (err) {
      toast(err.message, false);
    }
  }

  // ---------- início ----------
  (async function init() {
    try {
      const data = await api('/api/me');
      if (data.user) {
        state.user = data.user;
        await boot();
      } else {
        showAuth();
      }
    } catch {
      showAuth();
    }
  })();

})();

=== README.md ===
# Minhas Despesas

Um site para controle de despesas pessoais. Cada pessoa cria a sua conta, registra os gastos, organiza por categoria e vê quanto gastou no mês. O administrador cadastra as categorias, desativa contas de usuários e vê o total de gastos de todos.

**Tudo fica salvo de verdade** — fecha o navegador, abre de novo, os dados continuam lá. As senhas ficam protegidas. Não depende de serviços de login externo (sem Facebook, Google, etc.).

---

## Como funciona

- **Usuário comum:** entra com a conta → registra gastos (descrição, valor, categoria, data) → vê o total do mês, o total geral, e o histórico agrupado por dia com filtros por mês e categoria → exclui o que quiser.
- **Administrador:** além de tudo acima, tem uma aba "Administração" → cadastra e desativa categorias → desativa/reativa contas de usuários → vê o total gasto de todos, o total por usuário e a média por usuário.

---

## O que você precisa (1h no máximo, tudo gratuito)

1. Uma conta gratuita no **Supabase** (é o banco de dados). → [supabase.com](https://supabase.com)
2. Uma conta gratuita no **Cloudflare Workers** (é onde o site fica no ar na internet). → [dash.cloudflare.com](https://dash.cloudflare.com)

O código já está pronto. Você só vai fazer 4 passos: criar o banco, colocar o link dele no site, subir na internet, e cadastrar você como administrador.

> É só clicar e copiar/colar. Se travar em alguma parte, o erro aparece na tela em português.

---

## Passo 1 — Criar o banco de dados (Supabase)

1. Acesse [supabase.com](https://supabase.com) e clique em **Sign up** (crie uma conta grátis com e-mail).
2. Clique em **New project**.
   - *Name:* `minhas-despesas` (qualquer nome)
   - *Database password:* crie uma senha (anote se quiser, mas não é obrigatório)
   - *Region:* a mais próxima do Brasil (ex.: **South America (São Paulo)**)
   - Clique em **Create new project**. Espere uns 2–3 minutos aparecer "ready".
3. No menu lateral esquerdo, clique em **SQL Editor**.
4. Copie **todo** o conteúdo do arquivo `supabase/schema.sql` (deste projeto) e cole na janela SQL.
5. Clique no botão **Run** (rodar). Vai aparecer "Success". Pronto, o banco está criado.

### Agora copie os dois "links" do banco

1. Menu lateral → **Project Settings** (engrenagem) → **API**.
2. Copie a linha **Project URL** (parece `https://abcdefgh.supabase.co`).
3. Copie a linha **service_role** (a **Service Key**) — é uma chave longa. *Use esta e NÃO a "anon public key".*

Guarde as duas. Vamos usá-las agora e no Passo 3.

---

## Passo 2 — Rodar no seu computador (teste rápido)

Isso testa tudo antes de colocar na internet. Precisa ter [Node.js 18 ou mais novo](https://nodejs.org) instalado (no terminal, digite `node -v`).

```bash
# 1) Instale as dependências
npm install

# 2) Configure os dados do seu banco (substitua pelas chaves do Passo 1)
export SUPABASE_URL="https://SEU_PROJETO.supabase.co"
export SUPABASE_SERVICE_KEY="eyJhbGciOi..."
# No Windows (cmd), use:
#   set SUPABASE_URL=https://SEU_PROJETO.supabase.co
#   set SUPABASE_SERVICE_KEY=eyJhbGciOi...

# 3) Rode
npm start
```

Abra **http://localhost:8787** no navegador.

- Crie uma conta qualquer (nome, e-mail, senha). Ela já entra como usuário comum.
- Para o **primeiro** usuário virar administrador, faça este comando no terminal **do mesmo lugar** (Substitua `seu-usuario` pelo nome de usuário que você acabou de criar):

```bash
node -e "
import('./src/config.js').then(async ({supabase}) => {
  const { data } = await supabase.from('users').select('id').eq('username', 'seu-usuario').single();
  if (!data) { console.log('usuário não encontrado'); return; }
  await supabase.from('users').update({ is_admin: true }).eq('id', data.id);
  console.log('OK: ' + 'seu-usuario' + ' agora é administrador');
}).catch(e => console.error('ERRO', e.message));
"
```

Agora saia da conta e entre de novo: a aba **Administração** aparece.

Teste: adicione algumas categorias e alguns gastos. Feche o navegador e abra de novo — tudo continua lá. 🎉

## Passo 3 — Colocar no ar na internet (Cloudflare Workers)

1. No site do Cloudflare, crie sua conta grátis.
2. Em um terminal, entre na pasta do projeto e execute:

```bash
npm install
npx wrangler login
```

(Segue o link que aparecer para autorizar no navegador.)

3. Crie o worker:

```bash
npx wrangler init controle-de-despesas
```

Se perguntar, pode manter os nomes sugeridos (já existe um `wrangler.toml` configurado — se o `init` reescrever, mantenha as linhas `main = "src/server.js"` e `compatibility_flags = ["nodejs_compat"]`).

4. Cadastre as chaves do Supabase como segredos (a chave nunca fica exposta):

```bash
npx wrangler secret put SUPABASE_URL
# cole a Project URL e Enter
npx wrangler secret put SUPABASE_SERVICE_KEY
# cole a Service Key e Enter
```

5. Publicar:

```bash
npx wrangler deploy
```

O Cloudflare mostra uma **URL pública** (algo como `https://controle-de-despesas.<seu-usuario>.workers.dev`). **Essa é a página do seu site na internet.** Envie para as pessoas usarem.

> Para atualizar o site depois de mudar alguma coisa: rode de novo `npx wrangler deploy`.

- **Usuários comuns:** cada pessoa abre o site no link do Passo 3 e clica em **Criar conta**. Fácil.
- **Administrador:** como você já tem um admin criado no Passo 2, ele já funciona. Se precisar criar outro administrador depois, repita o comando `node -e "..."` do Passo 2 com o nome do usuário que quiser promover (ou me peça um script).

## Solução de problemas

| Problema | Causa provável / solução |
| --- | --- |
| `ERRO: variáveis de ambiente ... não configuradas` | No Passo 2 você esqueceu de rodar os `export`/`set`. Rode de novo antes de `npm start`. |
| `Erro 42P01` ou "relation does not exist" | A tabela não foi criada. Volte ao **Passo 1** e rode o `schema.sql` de novo. |
| `Failed to fetch` ao abrir | Use `http://localhost:8787` (não `https`) no seu computador, ou verifique se o `npm start` está rodando. |
| Não consigo criar conta | Confira se a **Service Key** (e não a anon key) está certa, e se o `schema.sql` rodou com sucesso. |
| Categoria não desativa | Já existe gasto naquela categoria. Exclua os gastos dela primeiro (proteção contra perder dados). |
| Admin não vê a aba | O usuário não foi promovido. Rode o comando `node -e "..."` do Passo 2. |

## Segurança (resumo)

- Senhas criptografadas com **bcrypt** (nunca ficam em texto).
- Sessão por cookie `HttpOnly` (o script da página não consegue roubar).
- Regras no banco impedem que um usuário leia os gastos de outro.
- Chaves do banco ficam como *segredos* no Cloudflare, nunca no navegador.
- Endereços de arquivo validados para evitar sair da pasta do site.
