# Marketplace de Serviços Freelance

Um site completo para que pessoas **ofereçam** serviços, **contratem** serviços de outras pessoas e que um **administrador** aprove/remova serviços, suspenda contas e veja tudo.

Tudo fica salvo **dentro do próprio site** (em um arquivo de dados), sem depender de nenhum serviço externo.

## Requisitos

- [Node.js](https://nodejs.org) instalado (versão 18 ou superior).
  Para checar, abra o terminal e digite: `node -v`

## Como instalar e rodar (no seu computador)

1. Abra o terminal **na pasta do projeto**.
2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o site:

   ```bash
   npm start
   ```

4. Abra no navegador: **http://localhost:3000**

> Se você quiser que a porta seja outra (ex.: 8080), use:
> ```bash
> PORT=8080 npm start
```

> **Windows (PowerShell):** `$env:PORT=8080; npm start`

## Conta de administrador (já criada)

- **E-mail:** `admin@marketplace.com`
- **Senha:** `admin123`

> **Troque essa senha depois que entrar**, em *Minha conta → Alterar senha*.

## Como publicar um serviço

Depois de entrar:

1. Vá em **Publicar serviço**.
2. Preencha título, categoria, descrição, preço e forma de pagamento.
3. Clique em **Publicar**.

> O serviço fica **“Pendente”** até o administrador aprovar. Somente serviços **aprovados** aparecem para os outros usuários.

## Como contratar um serviço

1. Abra **Explorar** e escolha um serviço aprovado.
2. Clique em **Ver detalhes** → **Contratar**.
3. Escreva uma mensagem para o prestador e confirme.

A partir daí o contrato aparece em **Meus contratos** para as duas pessoas. O prestador pode **Aceitar** ou **Recusar**; quando aceito, o **contratante** pode **Concluir**, encerrando o contrato.

## Como funciona a publicação (resumo do fluxo)

| Ação | Quem |
|---|---|
| Publica um serviço (fica “Pendente”) | Usuário que oferece |
| Aprova ou remove um serviço | Administrador |
| Contrata um serviço (cria “Contrato pendente”) | Usuário que contrata |
| Aceita ou recusa um contrato | Prestador do serviço |
| Conclui um contrato aceito | Contratante |
| Suspende/reativa contas, vê tudo | Administrador |

## Onde ficam os dados

- Os dados ficam no arquivo `data/dados.json` (criado automaticamente na primeira vez que alguém se cadastra).
- Para **zerar tudo** (devolver a plataforma ao estado inicial), apague a pasta `data/` e inicie o site de novo.

## Publicar na internet (de verdade)

Como você quer que funcione na internet, você precisa colocar este projeto em um servidor online. Veja 3 caminhos, do mais simples ao mais avançado:

### Opção A — Render (recomendado, grátis, mais fácil)
1. Crie uma conta gratuita no [Render.com](https://render.com).
2. Faça push deste projeto para um repositório no **GitHub**.
3. No Render: *New → Web Service* → escolha o repositório.
4. O Render detecta o `npm start` automaticamente. Clique em **Deploy**.
5. Pronto: o Render gera uma URL pública (ex.: `seu-nome.onrender.com`).

### Opção B — Railway (grátis para começar)
1. Crie uma conta no [Railway.app](https://railway.app).
2. *New Project → Deploy from GitHub repo* (ou envie as pastas por CLI).
3. Clique em **Deploy**.
4. A URL pública aparece na tela.

### Opção C — Seu próprio VPS (DigitalOcean, Hostinger VPS, etc.)
```bash
# no servidor
npm install
NODE_ENV=production PORT=3000 nohup npm start &
```
Depois aponte um domínio para o servidor (via DNS) e, se quiser HTTPS, use o [Caddy](https://caddyserver.com) ou o proxy do seu painel.

### ⚠️ Importante sobre os dados na internet
O site salva os dados em um arquivo no disco. Em serviços de hospedagem “efêmeros” (como o plano grátis do Render), esse arquivo **pode ser apagado** quando o serviço dorme. Para garantir que nada se perca, você tem duas opções:

1. **Disk permanente (Render):** em *Environment → Disks*, conecte um disco em `/data` e ajuste o caminho no `.env` (`DATA_DIR=/data`).
2. **Usar um banco de dados externo** (ex.: PostgreSQL + Prisma/Sequelize). É a solução mais robusta para produção. Posso migrar o projeto para um banco se você quiser.

> **Dica de segurança:** defina no ambiente de hospedagem a variável `ADMIN_INITIAL_PASSWORD` com uma senha forte e troque a senha logo após entrar.

import express from 'express';
import { mkdirSync, existsSync, readFileSync, writeFileSync } from 'node:fs';
import { join, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';
import crypto from 'node:crypto';

const __dirname = dirname(fileURLToPath(import.meta.url));
const DATA_DIR = process.env.DATA_DIR || join(__dirname, 'data');
const DB_FILE = join(DATA_DIR, 'dados.json');
const PORT = process.env.PORT || 3000;

/* ------------------------------------------------------------------ *
 *  Utilidades: senhas, ids, sessões
 * ------------------------------------------------------------------ */
const saltRnd = 1000; // tamanho do salt em bytes

function gerarId() {
  return crypto.randomBytes(12).toString('hex');
}

function gerarToken() {
  return crypto.randomBytes(24).toString('hex');
}

function hashSenha(senha, salt) {
  return crypto
    .scryptSync(String(senha), salt, 64)
    .toString('hex');
}

function senhaCorreta(senha, salt, hash) {
  const nova = hashSenha(senha, salt);
  const a = Buffer.from(nova, 'hex');
  const b = Buffer.from(hash, 'hex');
  if (a.length !== b.length) return false;
  return crypto.timingSafeEqual(a, b);
}

function novoUsuario() {
  const salt = crypto.randomBytes(saltRnd).toString('hex');
  return { salt, senhaHash: '' };
}

/* ------------------------------------------------------------------ *
 *  Persistência (arquivo JSON local)
 * ------------------------------------------------------------------ */
const DB = {
  usuarios: {},      // id -> { id, nome, email, salt, senhaHash, role, ativo, criadoEm }
  servicos: {},      // id -> serviço
  contratos: {},     // id -> contrato
  sessoes: {},       // token -> userId
  ordemServicos: [], // ids na ordem de criação
  ordemContratos: [] // ids na ordem de criação
};

function carregar() {
  if (!existsSync(DATA_DIR)) mkdirSync(DATA_DIR, { recursive: true });
  if (!existsSync(DB_FILE)) {
    // Cria a conta de administrador inicial.
    const salt = crypto.randomBytes(saltRnd).toString('hex');
    const email = (process.env.ADMIN_EMAIL || 'admin@marketplace.com').toLowerCase();
    const senha = process.env.ADMIN_INITIAL_PASSWORD || 'admin123';
    DB.usuarios['admin'] = {
      id: 'admin',
      nome: 'Administrador',
      email,
      salt,
      senhaHash: hashSenha(senha, salt),
      role: 'admin',
      ativo: true,
      criadoEm: new Date().toISOString()
    };
    salvar();
    console.log('▶ Banco inicializado. Admin: %s', email);
    return;
  }
  try {
    const dados = JSON.parse(readFileSync(DB_FILE, 'utf8'));
    Object.assign(DB, dados);
    console.log('▶ Banco carregado.');
  } catch (e) {
    console.error('✖ Erro ao carregar o banco de dados:', e.message);
    process.exit(1);
  }
}

function salvar() {
  // Grava de forma atômica simples: escreve em .tmp e renomeia.
  const tmp = DB_FILE + '.tmp';
  writeFileSync(tmp, JSON.stringify(DB, null, 2));
  renameSyncSafe(tmp, DB_FILE);
}

function renameSyncSafe(a, b) {
  try {
    const { renameSync } = require('node:fs');
    renameSync(a, b);
  } catch {
    // fallback para ambientes onde renameSync não foi importado no topo
    writeFileSync(b, readFileSync(a, 'utf8'));
    try { unlinkSync(a); } catch {}
  }
}
// Import helpers usados acima em alguns paths
import { renameSync, unlinkSync } from 'node:fs';

/* ------------------------------------------------------------------ *
 *  Validações
 * ------------------------------------------------------------------ */
function emailValido(e) {
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(e);
}

function usuarioAtivo(id) {
  const u = DB.usuarios[id];
  return u && u.ativo !== false;
}

function listarServicos() {
  return DB.ordemServicos
    .map(id => DB.servicos[id])
    .filter(Boolean)
    .sort((a, b) => b.criadoEm.localeCompare(a.criadoEm));
}

function listarContratos() {
  return DB.ordemContratos
    .map(id => DB.contratos[id])
    .filter(Boolean)
    .sort((a, b) => b.criadoEm.localeCompare(a.criadoEm));
}

function publico(u) {
  if (!u) return null;
  return { id: u.id, nome: u.nome, email: u.email, role: u.role, ativo: u.ativo !== false };
}

function resumoUsuario(p) {
  if (!p) return null;
  return { id: p.id, nome: p.nome, email: p.email, role: p.role };
}

function servicoPublico(s) {
  if (!s) return null;
  return {
    ...s,
    prestador: resumoUsuario(DB.usuarios[s.prestadorId])
  };
}

function contratoPublico(c) {
  if (!c) return null;
  const servico = DB.servicos[c.servicoId];
  const prestador = DB.usuarios[c.prestadorId];
  const contratante = DB.usuarios[c.contratanteId];
  return {
    ...c,
    servico: servico ? {
      id: servico.id,
      titulo: servico.titulo,
      categoria: servico.categoria,
      preco: servico.preco,
      formaPagamento: servico.formaPagamento
    } : null,
    prestador: resumoUsuario(prestador),
    contratante: resumoUsuario(contratante)
  };
}

function servicoAdmin(s) {
  const u = DB.usuarios[s.prestadorId];
  return {
    ...s,
    prestador: {
      id: u?.id || s.prestadorId,
      nome: u?.nome || 'Usuário removido',
      email: u?.email || '—',
      ativo: u?.ativo !== false
    }
  };
}

function contratoAdmin(c) {
  return {
    ...c,
    servicoTitulo: DB.servicos[c.servicoId]?.titulo || '—',
    prestador: DB.usuarios[c.prestadorId]
      ? { id: c.prestadorId, nome: DB.usuarios[c.prestadorId].nome, email: DB.usuarios[c.prestadorId].email }
      : { id: c.prestadorId, nome: 'Usuário removido', email: '—' },
    contratante: DB.usuarios[c.contratanteId]
      ? { id: c.contratanteId, nome: DB.usuarios[c.contratanteId].nome, email: DB.usuarios[c.contratanteId].email }
      : { id: c.contratanteId, nome: 'Usuário removido', email: '—' }
  };
}

/* ------------------------------------------------------------------ *
 *  Middlewares
 * ------------------------------------------------------------------ */
function auth(req, res, next) {
  const token = req.headers.authorization?.replace(/^Bearer\s+/i, '');
  if (!token) return res.status(401).json({ erro: 'Não autenticado' });
  const userId = DB.sessoes[token];
  if (!userId) return res.status(401).json({ erro: 'Sessão expirada' });
  const u = DB.usuarios[userId];
  if (!u || u.ativo === false) return res.status(401).json({ erro: 'Conta suspensa ou inexistente' });
  req.usuario = u;
  next();
}

function admin(req, res, next) {
  if (req.usuario?.role !== 'admin') {
    return res.status(403).json({ erro: 'Acesso restrito ao administrador' });
  }
  next();
}

/* ------------------------------------------------------------------ *
 *  Rotas públicas
 * ------------------------------------------------------------------ */
const app = express();
app.use(express.json({ limit: '256kb' }));
app.use(express.static(join(__dirname, 'public')));

app.post('/api/registro', (req, res) => {
  const { nome, email, senha } = req.body || {};
  if (!nome || String(nome).trim().length < 2)
    return res.status(400).json({ erro: 'Informe um nome (mínimo 2 caracteres).' });
  const emailN = String(email || '').toLowerCase().trim();
  if (!emailValido(emailN))
    return res.status(400).json({ erro: 'Informe um e-mail válido.' });
  if (Object.values(DB.usuarios).some(u => u.email === emailN))
    return res.status(409).json({ erro: 'Este e-mail já está cadastrado.' });
  if (!senha || String(senha).length < 6)
    return res.status(400).json({ erro: 'A senha precisa ter no mínimo 6 caracteres.' });

  const salt = crypto.randomBytes(saltRnd).toString('hex');
  const id = gerarId();
  const u = {
    id,
    nome: String(nome).trim(),
    email: emailN,
    salt,
    senhaHash: hashSenha(senha, salt),
    role: 'user',
    ativo: true,
    criadoEm: new Date().toISOString()
  };
  DB.usuarios[id] = u;

  const token = gerarToken();
  DB.sessoes[token] = id;
  salvar();
  res.status(201).json({ token, usuario: publico(u) });
});

app.post('/api/login', (req, res) => {
  const { email, senha } = req.body || {};
  const emailN = String(email || '').toLowerCase().trim();
  const u = Object.values(DB.usuarios).find(x => x.email === emailN);
  if (!u || !senhaCorreta(senha, u.salt, u.senhaHash))
    return res.status(401).json({ erro: 'E-mail ou senha incorretos.' });
  if (u.ativo === false)
    return res.status(403).json({ erro: 'Sua conta está suspensa. Fale com a administração.' });
  const token = gerarToken();
  DB.sessoes[token] = u.id;
  salvar();
  res.json({ token, usuario: publico(u) });
});

app.get('/api/servicos/publicos', (req, res) => {
  const lista = listarServicos()
    .filter(s => s.status === 'aprovado')
    .map(servicoPublico);
  res.json({ servicos: lista });
});

/* ------------------------------------------------------------------ *
 *  Rotas autenticadas
 * ------------------------------------------------------------------ */
app.get('/api/conta', auth, (req, res) => {
  res.json({ usuario: publico(req.usuario) });
});

app.post('/api/logout', auth, (req, res) => {
  const token = req.headers.authorization?.replace(/^Bearer\s+/i, '');
  delete DB.sessoes[token];
  salvar();
  res.json({ ok: true });
});

app.patch('/api/conta/senha', auth, (req, res) => {
  const { senhaAtual, novaSenha } = req.body || {};
  if (!senhaAtual || !novaSenha)
    return res.status(400).json({ erro: 'Informe a senha atual e a nova senha.' });
  if (!senhaCorreta(senhaAtual, req.usuario.salt, req.usuario.senhaHash))
    return res.status(400).json({ erro: 'A senha atual está incorreta.' });
  if (String(novaSenha).length < 6)
    return res.status(400).json({ erro: 'A nova senha precisa ter no mínimo 6 caracteres.' });
  const salt = crypto.randomBytes(saltRnd).toString('hex');
  req.usuario.salt = salt;
  req.usuario.senhaHash = hashSenha(novaSenha, salt);
  salvar();
  res.json({ ok: true });
});

// ——— Publicar serviço ———
app.post('/api/servicos', auth, (req, res) => {
  const b = req.body || {};
  const titulo = String(b.titulo || '').trim();
  const categoria = String(b.categoria || '').trim();
  const descricao = String(b.descricao || '').trim();
  const preco = Number(b.preco);
  const formaPagamento = String(b.formaPagamento || 'Por hora').trim();

  if (titulo.length < 4) return res.status(400).json({ erro: 'Título curto demais (mínimo 4 caracteres).' });
  if (categoria.length < 2) return res.status(400).json({ erro: 'Informe a categoria.' });
  if (descricao.length < 10) return res.status(400).json({ erro: 'A descrição precisa ter ao menos 10 caracteres.' });
  if (!Number.isFinite(preco) || preco < 0) return res.status(400).json({ erro: 'Informe um preço válido (número maior ou igual a 0).' });

  const id = gerarId();
  const s = {
    id,
    prestadorId: req.usuario.id,
    titulo,
    categoria,
    descricao,
    preco,
    formaPagamento,
    status: 'pendente',
    criadoEm: new Date().toISOString()
  };
  DB.servicos[id] = s;
  DB.ordemServicos.push(id);
  salvar();
  res.status(201).json({ servico: servicoPublico(s) });
});

app.get('/api/servicos/meus', auth, (req, res) => {
  const meus = listarServicos()
    .filter(s => s.prestadorId === req.usuario.id)
    .map(servicoPublico);
  res.json({ servicos: meus });
});

// ——— Contratos ———
app.post('/api/contratos', auth, (req, res) => {
  const { servicoId, mensagem } = req.body || {};
  const s = DB.servicos[servicoId];
  if (!s) return res.status(404).json({ erro: 'Serviço não encontrado.' });
  if (s.status !== 'aprovado') return res.status(400).json({ erro: 'Este serviço não está aprovado.' });
  if (s.prestadorId === req.usuario.id)
    return res.status(400).json({ erro: 'Você não pode contratar o seu próprio serviço.' });

  const contrato = {
    id: gerarId(),
    servicoId: s.id,
    prestadorId: s.prestadorId,
    contratanteId: req.usuario.id,
    mensagem: String(mensagem || '').trim(),
    status: 'pendente', // pendente | aceito | recusado | concluido
    criadoEm: new Date().toISOString()
  };
  DB.contratos[contrato.id] = contrato;
  DB.ordemContratos.push(contrato.id);
  salvar();
  res.status(201).json({ contrato: contratoPublico(contrato) });
});

app.get('/api/contratos/meus', auth, (req, res) => {
  const meus = listarContratos()
    .filter(c => c.prestadorId === req.usuario.id || c.contratanteId === req.usuario.id)
    .map(contratoPublico);
  res.json({ contratos: meus });
});

app.post('/api/contratos/:id/acao', auth, (req, res) => {
  const c = DB.contratos[req.params.id];
  if (!c) return res.status(404).json({ erro: 'Contrato não encontrado.' });
  const { acao } = req.body || {};
  const ePrestador = req.usuario.id === c.prestadorId;
  const eContratante = req.usuario.id === c.contratanteId;

  if (acao === 'aceitar') {
    if (!ePrestador) return res.status(403).json({ erro: 'Apenas o prestador pode aceitar.' });
    if (c.status !== 'pendente') return res.status(400).json({ erro: 'Já houve uma decisão sobre este contrato.' });
    c.status = 'aceito';
  } else if (acao === 'recusar') {
    if (!ePrestador) return res.status(403).json({ erro: 'Apenas o prestador pode recusar.' });
    if (c.status !== 'pendente') return res.status(400).json({ erro: 'Já houve uma decisão sobre este contrato.' });
    c.status = 'recusado';
  } else if (acao === 'concluir') {
    if (!eContratante) return res.status(403).json({ erro: 'Apenas o contratante pode concluir.' });
    if (c.status !== 'aceito') return res.status(400).json({ erro: 'Só é possível concluir um contrato aceito.' });
    c.status = 'concluido';
  } else {
    return res.status(400).json({ erro: 'Ação inválida.' });
  }
  salvar();
  res.json({ contrato: contratoPublico(c) });
});

/* ------------------------------------------------------------------ *
 *  Rotas do administrador
 * ------------------------------------------------------------------ */
app.get('/api/admin/servicos', auth, admin, (req, res) => {
  res.json({ servicos: listarServicos().map(servicoAdmin) });
});

app.get('/api/admin/contratos', auth, admin, (req, res) => {
  res.json({ contratos: listarContratos().map(contratoAdmin) });
});

app.get('/api/admin/usuarios', auth, admin, (req, res) => {
  const usuarios = Object.values(DB.usuarios).map(publico);
  res.json({ usuarios });
});

app.post('/api/admin/servicos/:id/aprovar', auth, admin, (req, res) => {
  const s = DB.servicos[req.params.id];
  if (!s) return res.status(404).json({ erro: 'Serviço não encontrado.' });
  s.status = 'aprovado';
  salvar();
  res.json({ servico: servicoAdmin(s) });
});

app.post('/api/admin/servicos/:id/remover', auth, admin, (req, res) => {
  const s = DB.servicos[req.params.id];
  if (!s) return res.status(404).json({ erro: 'Serviço não encontrado.' });
  delete DB.servicos[s.id];
  DB.ordemServicos = DB.ordemServicos.filter(x => x !== s.id);
  salvar();
  res.json({ ok: true });
});

app.post('/api/admin/usuarios/:id/toggle', auth, admin, (req, res) => {
  const u = DB.usuarios[req.params.id];
  if (!u) return res.status(404).json({ erro: 'Usuário não encontrado.' });
  if (u.role === 'admin')
    return res.status(400).json({ erro: 'Não é possível suspender o administrador.' });
  u.ativo = u.ativo === false ? true : false;
  // Remove sessões ativas do usuário suspenso.
  if (u.ativo === false) {
    for (const [t, uid] of Object.entries(DB.sessoes)) {
      if (uid === u.id) delete DB.sessoes[t];
    }
  }
  salvar();
  res.json({ usuario: publico(u) });
});

/* ------------------------------------------------------------------ *
 *  Erros e fallback SPA
 * ------------------------------------------------------------------ */
app.use((req, res) => {
  if (req.path.startsWith('/api/')) return res.status(404).json({ erro: 'Rota não encontrada' });
  res.sendFile(join(__dirname, 'public', 'index.html'));
});

app.use((err, req, res, next) => {
  console.error(err);
  res.status(500).json({ erro: 'Erro interno do servidor' });
});

/* ------------------------------------------------------------------ *
 *  Start
 * ------------------------------------------------------------------ */
carregar();
app.listen(PORT, () => {
  console.log(`✔ Marketplace rodando em http://localhost:${PORT}`);
});

  const palette = ['#ff5a1f','#1e5fd9','#0f8a5f','#7c3aed','#db2777','#b77a00','#0891b2'];

const $ = (sel, ctx = document) => ctx.querySelector(sel);

function el(html) {
  const t = document.createElement('template');
  t.innerHTML = html.trim();
  return t.content.firstElementChild;
}

function esc(s) {
  return String(s ?? '')
    .replace(/[&<>"']/g, c => ({
      '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;'
    }[c]));
}

function iniciais(nome = '') {
  const p = String(nome).trim().split(/\s+/).slice(0, 2);
  return p.map(x => x[0]).join('').toUpperCase() || '?';
}

function moeda(v) {
  const n = Number(v || 0);
  return new Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' }).format(n);
}

function dataRelativa(iso) {
  if (!iso) return '';
  const d = new Date(iso);
  const diff = (Date.now() - d.getTime()) / 1000;
  if (diff < 60) return 'agora';
  if (diff < 3600) return `há ${Math.floor(diff / 60)} min`;
  if (diff < 86400) return `há ${Math.floor(diff / 3600)} h`;
  if (diff < 86400 * 7) return `há ${Math.floor(diff / 86400)} d`;
  return d.toLocaleDateString('pt-BR');
}

function toast(msg, tipo = 'info') {
  const icons = {
    success: 'M5 12l5 5L20 7',
    error:   'M6 6l12 12M18 6L6 18',
    info:    'M12 8v4m0 4h.01'
  };
  const t = el(`
    <div class="toast toast--${tipo}" role="status">
      <span class="toast__icon">
        <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.2" stroke-linecap="round" stroke-linejoin="round">
          <path d="${icons[tipo] || icons.info}"/>
        </svg>
      </span>
      <div class="toast__msg">${esc(msg)}</div>
    </div>
  `);
  $('#toastStack').appendChild(t);
  setTimeout(() => {
    t.classList.add('is-leaving');
    setTimeout(() => t.remove(), 220);
  }, 3600);
}

function api(path, opts = {}) {
  const headers = opts.headers || {};
  if (opts.body && typeof opts.body !== 'string') headers['Content-Type'] = 'application/json';
  if (API.token) headers['Authorization'] = 'Bearer ' + API.token;
  return fetch('/api' + path, {
    method: opts.method || (opts.body ? 'POST' : 'GET'),
    headers,
    body: opts.body ? JSON.stringify(opts.body) : undefined
  }).then(async res => {
    let data = null;
    try { data = await res.json(); } catch { data = {}; }
    if (!res.ok) {
      const err = new Error(data.erro || 'Erro');
      err.status = res.status;
      err.data = data;
      throw err;
    }
    return data;
  });
}

    if (isAdmin) {

    } else {

      const pend = state.data.meusContratos.filter(c => c.status === 'pendente' && c.prestadorId === API.user.id).length;
      links.push({ id: 'contratos', label: 'Meus contratos', badge: pend || null });

    links.push({ id: 'conta', label: 'Minha conta' });
  } else {
    links.push({ id: 'explorar', label: 'Explorar serviços' });
  }

  nav.innerHTML = links.map(l => `

  }));

  if (API.user) {
    userBox.hidden = false;

}

function renderPage() {
  const root = $('#app');
  const pag = state.route;
  if (!API.user && !['home', 'explorar', 'auth'].includes(pag)) {
    state.route = 'auth';
    return renderPage();
  }
  root.innerHTML = '';
  let page;
  switch (pag) {
    case 'home':         page = renderHome(); break;
    case 'explorar':     page = renderExplorar(); break;
    case 'meus-servicos':page = renderMeusServicos(); break;
    case 'publicar':     page = renderPublicar(); break;
    case 'contratos':    page = renderContratos(); break;
    case 'admin':        page = renderAdmin(); break;
    case 'conta':        page = renderConta(); break;
    case 'auth':         page = renderAuth(); break;
    default:             page = renderHome();
  }
  page.classList.add('page', 'is-active');
  root.appendChild(page);

  // dados
  if (pag === 'home') carregarHome();
  if (pag === 'explorar') carregarExplorar();
  if (pag === 'meus-servicos') carregarMeus();
  if (pag === 'contratos') carregarContratos();
  if (pag === 'admin') carregarAdmin();
  if (pag === 'conta' && API.user?.role === 'admin') carregarConteudoAdmin();
}

      });

function filtrarServicos(lista) {
  const { q, cat } = state.filtro;
  return lista.filter(s => {
    if (cat && s.categoria !== cat) return false;
    if (q) {
      const t = (s.titulo + ' ' + s.descricao + ' ' + (s.prestador?.nome || '')).toLowerCase();
      if (!t.includes(q.toLowerCase())) return false;
    }
    return true;
  });
}

async function carregarContratos() {
  try {
    const r = await api('/contratos/meus');
    state.data.meusContratos = r.contratos;
    renderNav();
    const wrap = $('#contratosWrap');
    if (!r.contratos.length) {
      wrap.innerHTML = `<div class="empty" style="border:0;background:transparent">
        <div class="empty__icon"><svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M14 2H6a2 2 0 0 0-2 2v16a2 2 0 0 0 2 2h12a2 2 0 0 0 2-2V8z"/><path d="M14 2v6h6"/></svg></div>
        <h4>Nenhum contrato ainda</h4>
        <p>Quando você contratar ou ser contratado, o contrato aparecerá aqui.</p>
      </div>`;
      return;
    }
    const rows = r.contratos.map(c => {
      const euPrestador = c.prestadorId === API.user.id;
      const outro = euPrestador ? c.contratante : c.prestador;
      const acoes = [];
      if (c.status === 'pendente' && euPrestador) {
        acoes.push(`<button class="btn btn--primary btn--small" data-acao="aceitar">Aceitar</button>`);
        acoes.push(`<button class="btn btn--danger btn--small" data-acao="recusar">Recusar</button>`);
      }
      if (c.status === 'aceito' && !euPrestador) {
        acoes.push(`<button class="btn btn--subtle btn--small" data-acao="concluir">Concluir</button>`);
      }
      return `
        <tr data-id="${esc(c.id)}">
          <td>
            <div class="cell-strong">${esc(c.servico?.titulo || '—')}</div>
            <div class="cell-muted">Criado ${esc(dataRelativa(c.criadoEm))}</div>
          </td>
          <td>
            <div style="display:flex;align-items:center;gap:8px">
              <span class="avatar avatar--sm" style="background:${corInicial(outro?.nome)}">${esc(iniciais(outro?.nome))}</span>
              ${esc(outro?.nome || '—')}
            </div>
            <div class="cell-muted">${euPrestador ? 'contratante' : 'prestador'}</div>
          </td>
          <td>
            <span class="cell-strong">${moeda(c.servico?.preco || 0)}</span>
            <div class="cell-muted">${esc(c.servico?.formaPagamento || '')}</div>
          </td>
          <td><span class="status-pill status-pill--${esc(c.status)}">${esc(c.status)}</span></td>
          <td>
            <div class="cell-actions">
              ${c.mensagem ? `<span class="cell-muted small" title="${esc(c.mensagem)}">✉️ ${esc(truncar(c.mensagem, 40))}</span>` : ''}
              ${acoes.join('')}
            </div>
          </td>
        </tr>
      `;
    }).join('');
    wrap.innerHTML = `
      <table class="data">
        <thead><tr><th>Serviço</th><th>Outro participante</th><th>Valor</th><th>Status</th><th>Ações</th></tr></thead>
        <tbody>${rows}</tbody>
      </table>
    `;
    $$('#contratosWrap [data-acao]').forEach(b => b.addEventListener('click', e => {
      const tr = e.target.closest('tr');
      const id = tr.dataset.id;
      acaoContrato(id, b.dataset.acao);
    }));
  } catch (e) { console.error(e); }
}

function truncar(s, n) { s = String(s); return s.length > n ? s.slice(0, n) + '…' : s; }

async function acaoContrato(id, acao) {
  try {
    await api(`/contratos/${id}/acao`, { method: 'POST', body: { acao } });
    const msgs = {
      aceitar: 'Contrato aceito.',
      recusar: 'Contrato recusado.',
      concluir: 'Contrato concluído.'
    };
    toast(msgs[acao] || 'OK', 'success');
    carregarContratos();
  } catch (err) {
    toast(err.message || 'Erro.', 'error');
  }
}

/* ---------------------------------- *
 *  Modal de serviço (detalhes + contratar)

  const c = categoriaPorId(s.categoria);

  const podeContratar = !me && s.status === 'aprovado';
  const backdrop = el(`
    <div class="modal-backdrop" id="modalBackdrop">
      <div class="modal" role="dialog" aria-modal="true">
        <div class="modal__head">
          <div>
            <h3 class="modal__title">${esc(s.titulo)}</h3>

              <span class="service-card__cat" style="--cat-color:${esc(c.cor)};display:inline-flex">${esc(c.nome)}</span>
              <span class="status-pill status-pill--${esc(s.status)}" style="margin-left:8px">${esc(s.status)}</span>
            </div>
          </div>
          <button class="modal__close" data-fechar aria-label="Fechar">
            <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.2" stroke-linecap="round"><path d="M6 6l12 12M18 6L6 18"/></svg>

          <div class="service-detail__meta">
            <div class="meta-tile">
              <div class="meta-tile__label">Preço</div>
              <div class="meta-tile__value">${moeda(s.preco)}</div>
            </div>
            <div class="meta-tile">
              <div class="meta-tile__label">Forma</div>
              <div class="meta-tile__value">${esc(s.formaPagamento || '—')}</div>
            </div>
            <div class="meta-tile">
              <div class="meta-tile__label">Publicado</div>
              <div class="meta-tile__value">${esc(dataRelativa(s.criadoEm))}</div>
            </div>
          </div>
          <div class="service-detail__seller">
            <span class="avatar" style="background:${corInicial(s.prestador?.nome)}">${esc(iniciais(s.prestador?.nome))}</span>
            <div>
              <div class="cell-strong">${esc(s.prestador?.nome || 'Anônimo')}</div>
              <div class="cell-muted">Prestador do serviço</div>
            </div>
          </div>
          ${podeContratar ? `
            <div class="divider"></div>
            <div class="field">
              <label for="msgContrato">Mensagem para o prestador</label>
              <textarea id="msgContrato" placeholder="Conte o que você precisa, prazos, detalhes…"></textarea>
            </div>
          ` : ''}
        </div>
        <div class="modal__actions">
          <button class="btn btn--ghost" data-fechar>Fechar</button>
          ${podeContratar ? `<button class="btn btn--primary" data-contratar="${esc(s.id)}">Contratar</button>` : ''}
        </div>
      </div>
    </div>
  `);
  document.body.appendChild(backdrop);
  backdrop.addEventListener('click', e => {
    if (e.target.id === 'modalBackdrop' || e.target.closest('[data-fechar]')) backdrop.remove();
  });
  const btn = backdrop.querySelector('[data-contratar]');
  if (btn) btn.addEventListener('click', async () => {
    const msg = backdrop.querySelector('#msgContrato').value;
    try {
      await api('/contratos', { method: 'POST', body: { servicoId: s.id, mensagem: msg } });
      toast('Contratação enviada! O prestador foi notificado.', 'success');
      backdrop.remove();
      if (!API.user) { /* nunca acontece */ }
      navegar('contratos');
    } catch (err) {
      toast(err.message || 'Erro ao contratar.', 'error');
    }
  });
}

function mostrarErro(msg) {
  const e = $('#authError');
  if (!e) return;
  e.textContent = msg;
  e.hidden = false;
  e.scrollIntoView({ behavior: 'smooth', block: 'nearest' });
}

async function submitAuth(e) {
  e.preventDefault();
  const form = e.target;
  const isLogin = form.id === 'formLogin';
  const body = isLogin
    ? { email: form.email.value, senha: form.senha.value }
    : { nome: form.nome.value, email: form.email.value, senha: form.senha.value };
  try {
    const r = await api(isLogin ? '/login' : '/registro', { method: 'POST', body });
    API.setSession(r.token, r.usuario);
    toast(isLogin ? 'Bem-vindo(a) de volta, ' + r.usuario.nome.split(' ')[0] + '!' : 'Conta criada com sucesso!', 'success');
    navegar(r.usuario.role === 'admin' ? 'admin' : 'home');
  } catch (err) {
    mostrarErro(err.message || 'Erro.');
  }
}

async function carregarAdmin() {
  try {
    const [s, c, u] = await Promise.all([
      api('/admin/servicos'), api('/admin/contratos'), api('/admin/usuarios')
    ]);
    state.data.adminServicos = s.servicos;
    state.data.adminContratos = c.contratos;
    state.data.adminUsuarios = u.usuarios;
    const counts = {
      servicos: s.servicos.length,
      contratos: c.contratos.length,
      usuarios: u.usuarios.length
    };
    $$('[data-count]').forEach(el => el.textContent = counts[el.dataset.count] ?? '–');
    renderNav();
    renderConteudoAdmin();
  } catch (e) { console.error(e); }
}

function renderConteudoAdmin() {
  const panel = $('#adminPanel');
  if (!panel) return;
  if (state.adminTab === 'servicos') panel.innerHTML = adminServicosHTML();
  else if (state.adminTab === 'contratos') panel.innerHTML = adminContratosHTML();
  else if (state.adminTab === 'usuarios') panel.innerHTML = adminUsuariosHTML();
  $$('#adminPanel [data-acao]').forEach(b => b.addEventListener('click', e => {
    const tr = e.target.closest('tr, .list-item');
    const id = tr?.dataset.id;
    adminAcao(b.dataset.acao, id);
  }));
  $$('#adminPanel [data-toggle]').forEach(b => b.addEventListener('click', e => {
    const tr = e.target.closest('tr');
    toggleUsuario(tr.dataset.id, b.dataset.toggle);
  }));
}

async function adminAcao(acao, id) {
  if (!id) return;
  try {
    if (acao === 'aprovar') {
      await api(`/admin/servicos/${id}/aprovar`, { method: 'POST' });
      toast('Serviço aprovado.', 'success');
    } else if (acao === 'remover') {
      if (!confirm('Remover este serviço permanentemente?')) return;
      await api(`/admin/servicos/${id}/remover`, { method: 'POST' });
      toast('Serviço removido.', 'success');
    }
    carregarAdmin();
  } catch (err) {
    toast(err.message || 'Erro.', 'error');
  }
}

async function toggleUsuario(id, toggle) {
  try {
    const r = await api(`/admin/usuarios/${id}/toggle`, { method: 'POST' });
    toast(r.usuario.ativo ? 'Usuário reativado.' : 'Usuário suspenso.', 'success');
    carregarAdmin();
  } catch (err) {
    toast(err.message || 'Erro.', 'error');
  }
}
