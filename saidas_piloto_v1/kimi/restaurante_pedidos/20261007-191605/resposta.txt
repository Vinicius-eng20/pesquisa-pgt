# 🍽️ Sabor & Arte - Sistema de Pedidos para Restaurante

Este é um sistema completo de pedidos para restaurante, pronto para funcionar na internet. Ele já vem com tudo dentro do próprio site: não precisa contratar banco de dados, nem conectar outros serviços.

## ✅ O que este sistema faz

### 👤 Para os clientes
- Criar conta e entrar com login e senha
- Ver o cardápio com fotos, descrições e preços
- Adicionar pratos ao carrinho e finalizar pedidos
- Acompanhar a situação dos seus pedidos (Recebido → Preparando → A caminho → Entregue)
- Ver o histórico de todos os pedidos já feitos
- Cancelar pedidos que ainda não começaram a ser preparados

### 👔 Para o gerente
- Cadastrar, editar e remover pratos do cardápio
- Ver todos os pedidos de todos os clientes
- Mudar a situação dos pedidos (ex.: marcar como "Preparando", "Saiu para entrega", etc.)
- Ver estatísticas do dia (faturamento, total de pedidos)

## 🔐 Contas já criadas (você pode criar outras)

## 🚀 Como colocar no ar (funcionando de verdade na internet)

O jeito mais fácil é usar o **Render** (gratuito). Você não precisa instalar nada no seu computador, só precisa de uma conta no GitHub e no Render.

### Passo 1: Colocar os arquivos no GitHub
1. Crie uma conta gratuita em [github.com](https://github.com) (se não tiver)
2. Clique em **"New repository"** (Novo repositório)
3. Dê um nome, por exemplo: `meu-restaurante`
4. Deixe como **Public** e clique em **"Create repository"**
5. Na página que abrir, clique em **"uploading an existing file"**
6. Arraste todos os arquivos deste projeto (`server.js`, `package.json`, `README.md` e a pasta `public` inteira) para a página
7. Clique no botão verde **"Commit changes"** no final da página

### Passo 2: Colocar no ar com o Render (gratuito)
1. Crie uma conta gratuita em [render.com](https://render.com) (pode entrar com a conta do GitHub)
2. No painel, clique em **"New +"** → **"Web Service"**
3. Escolha **"Build and deploy from a Git repository"** e clique em **Next**
4. Conecte sua conta do GitHub e selecione o repositório `meu-restaurante`
5. Preencha assim:
   - **Name:** `meu-restaurante` (será o endereço do site)
   - **Region:** deixe o padrão
   - **Branch:** `main`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** selecione **Free**
6. Clique em **"Create Web Service"**
7. Aguarde 2 a 5 minutos. Quando aparecer **"Live"**, seu site está no ar! 🎉
8. O endereço será algo como: `https://meu-restaurante.onrender.com` — é só mandar esse link para os clientes!

### ⚠️ Importante sobre os dados
Os dados ficam salvos em um arquivo chamado `database.json` dentro do servidor. No plano gratuito do Render, se o servidor for reiniciado do zero (raro), os dados voltam ao padrão. Para uso profissional intenso, considere o plano pago do Render com "Disco Persistente" (USD ~7/mês) — aí os dados ficam 100% garantidos para sempre.

## 💻 Como testar no seu próprio computador (opcional)

Se você quiser testar antes de colocar no ar:

1. Instale o **Node.js** no seu computador: baixe em [nodejs.org](https://nodejs.org) (versão LTS, clique em Next, Next, Finish)
2. Baixe os arquivos deste projeto em uma pasta, por exemplo `C:\meu-restaurante`
3. Abra o **Prompt de Comando** (Windows) ou **Terminal** (Mac/Linux) dentro dessa pasta
4. Digite os comandos abaixo, um de cada vez:

```bash
npm install
npm start
```

5. Abra o navegador e acesse: **http://localhost:3000**

## 🛠️ Como usar depois de no ar

1. **Primeiro acesso:** entre como gerente (`gerente@restaurante.com` / `admin123`) e personalize o cardápio com os pratos do seu restaurante (você pode colocar link de fotos ou deixar sem foto)
2. **Clientes:** eles acessam o link do site, clicam em "Criar conta" e já podem pedir
3. **Pedidos:** quando um cliente fizer um pedido, ele aparece na aba "Pedidos" do gerente na hora (atualiza sozinho a cada 10 segundos)
4. **Situação:** o gerente clica nos botões para avançar o pedido: Recebido → Preparando → Pronto / A caminho → Entregue

function carregarBanco() {
  try {
    if (fs.existsSync(DB_FILE)) {
      const dados = JSON.parse(fs.readFileSync(DB_FILE, 'utf8'));
      // Garante que todas as chaves existem (proteção contra arquivo corrompido)
      const inicial = criarBancoInicial();
      return {
        usuarios: dados.usuarios || inicial.usuarios,
        pratos: dados.pratos || inicial.pratos,
        pedidos: dados.pedidos || inicial.pedidos,
        proximoIdUsuario: dados.proximoIdUsuario || inicial.proximoIdUsuario,
        proximoIdPrato: dados.proximoIdPrato || inicial.proximoIdPrato,
        proximoIdPedido: dados.proximoIdPedido || inicial.proximoIdPedido
      };
    }
  } catch (erro) {
    console.log('⚠️ Erro ao ler banco de dados, criando novo:', erro.message);
  }
  const novo = criarBancoInicial();
  salvarBanco(novo);
  return novo;
}

let dbCarregado = null;
let salvamentoPendente = false;

function db() {
  if (!dbCarregado) dbCarregado = carregarBanco();
  return dbCarregado;
}

function salvarBanco(dados) {
  if (dados) dbCarregado = dados;
  if (salvamentoPendente) return;
  salvamentoPendente = true;
  setImmediate(() => {
    try {
      fs.writeFileSync(DB_FILE, JSON.stringify(dbCarregado, null, 2));
    } catch (erro) {
      console.log('⚠️ Erro ao salvar banco:', erro.message);
    }
    salvamentoPendente = false;
  });
}

function exigirLogin(req, res, next) {
  if (!req.session.usuarioId) {
    return res.status(401).json({ erro: 'Você precisa entrar na sua conta primeiro.' });
  }
  next();
}

function exigirGerente(req, res, next) {
  if (!req.session.usuarioId) {
    return res.status(401).json({ erro: 'Você precisa entrar na sua conta primeiro.' });
  }
  const usuario = db().usuarios.find(u => u.id === req.session.usuarioId);
  if (!usuario || usuario.papel !== 'gerente') {
    return res.status(403).json({ erro: 'Somente o gerente pode fazer isso.' });
  }
  next();
}

function usuarioAtual(req) {
  return db().usuarios.find(u => u.id === req.session.usuarioId);
}

function limparTexto(texto, tamanhoMax = 500) {
  if (typeof texto !== 'string') return '';
  return texto.trim().slice(0, tamanhoMax);
}

app.post('/api/cadastro', (req, res) => {
  const nome = limparTexto(req.body.nome, 100);
  const email = limparTexto(req.body.email, 150).toLowerCase();
  const senha = String(req.body.senha || '');

  if (!nome || nome.length < 2) {
    return res.status(400).json({ erro: 'Informe seu nome completo.' });
  }
  if (!email || !email.includes('@') || !email.includes('.')) {
    return res.status(400).json({ erro: 'Informe um e-mail válido.' });
  }
  if (senha.length < 6) {
    return res.status(400).json({ erro: 'A senha precisa ter pelo menos 6 caracteres.' });
  }
  if (db().usuarios.find(u => u.email === email)) {
    return res.status(400).json({ erro: 'Este e-mail já está cadastrado. Tente entrar.' });
  }

  const novoUsuario = {
    id: db().proximoIdUsuario++,
    nome,
    email,
    senha: bcrypt.hashSync(senha, 10),
    papel: 'cliente'
  };
  db().usuarios.push(novoUsuario);
  salvarBanco();

  req.session.usuarioId = novoUsuario.id;
  res.json({ ok: true, usuario: { id: novoUsuario.id, nome, email, papel: 'cliente' } });
});

app.post('/api/entrar', (req, res) => {
  const email = limparTexto(req.body.email, 150).toLowerCase();
  const senha = String(req.body.senha || '');

  const usuario = db().usuarios.find(u => u.email === email);
  if (!usuario || !bcrypt.compareSync(senha, usuario.senha)) {
    return res.status(401).json({ erro: 'E-mail ou senha incorretos.' });
  }

  req.session.usuarioId = usuario.id;
  res.json({ ok: true, usuario: { id: usuario.id, nome: usuario.nome, email: usuario.email, papel: usuario.papel } });
});

app.post('/api/sair', (req, res) => {
  req.session.destroy(() => {
    res.json({ ok: true });
  });
});

  const nome = limparTexto(req.body.nome, 100);
  const descricao = limparTexto(req.body.descricao, 300);
  const preco = parseFloat(req.body.preco);
  const categoria = limparTexto(req.body.categoria, 50);
  const foto = limparTexto(req.body.foto, 500);

  if (!nome) return res.status(400).json({ erro: 'Informe o nome do prato.' });
  if (isNaN(preco) || preco <= 0) return res.status(400).json({ erro: 'Informe um preço válido.' });

  prato.nome = nome;
  prato.descricao = descricao;
  prato.preco = Math.round(preco * 100) / 100;
  prato.categoria = categoria || 'Geral';
  prato.foto = foto;
  if (typeof req.body.ativo === 'boolean') prato.ativo = req.body.ativo;

  salvarBanco();
  res.json({ ok: true, prato });
});

const SITUACOES = ['Recebido', 'Preparando', 'Pronto', 'A caminho', 'Entregue', 'Cancelado'];

app.post('/api/pedidos', exigirLogin, (req, res) => {
  const usuario = usuarioAtual(req);
  if (!usuario) return res.status(401).json({ erro: 'Faça login novamente.' });

  const itens = Array.isArray(req.body.itens) ? req.body.itens : [];
  const endereco = limparTexto(req.body.endereco, 300);
  const observacao = limparTexto(req.body.observacao, 300);

  if (itens.length === 0) {
    return res.status(400).json({ erro: 'Seu carrinho está vazio.' });
  }
  if (!endereco) {
    return res.status(400).json({ erro: 'Informe o endereço de entrega.' });
  }
  if (itens.length > 50) {
    return res.status(400).json({ erro: 'Pedido muito grande. Divida em dois pedidos.' });
  }

  let total = 0;
  const itensValidados = [];
  for (const item of itens) {
    const prato = db().pratos.find(p => p.id === parseInt(item.pratoId) && p.ativo);
    const quantidade = parseInt(item.quantidade);
    if (!prato) {
      return res.status(400).json({ erro: 'Um dos pratos não está mais disponível no cardápio.' });
    }
    if (isNaN(quantidade) || quantidade < 1 || quantidade > 99) {
      return res.status(400).json({ erro: 'Quantidade inválida em um dos itens.' });
    }
    total += prato.preco * quantidade;
    itensValidados.push({
      pratoId: prato.id,
      nome: prato.nome,
      preco: prato.preco,
      quantidade
    });
  }

  const novoPedido = {
    id: db().proximoIdPedido++,
    clienteId: usuario.id,
    clienteNome: usuario.nome,
    clienteEmail: usuario.email,
    itens: itensValidados,
    total: Math.round(total * 100) / 100,
    endereco,
    observacao,
    situacao: 'Recebido',
    criadoEm: new Date().toISOString(),
    atualizadoEm: new Date().toISOString()
  };

  db().pedidos.push(novoPedido);
  salvarBanco();
  res.json({ ok: true, pedido: novoPedido });
});

app.get('/api/meus-pedidos', exigirLogin, (req, res) => {
  const meus = db().pedidos

app.put('/api/pedidos/:id/situacao', exigirGerente, (req, res) => {
  const pedido = db().pedidos.find(p => p.id === parseInt(req.params.id));
  if (!pedido) return res.status(404).json({ erro: 'Pedido não encontrado.' });

  const novaSituacao = limparTexto(req.body.situacao, 30);
  if (!SITUACOES.includes(novaSituacao)) {
    return res.status(400).json({ erro: 'Situação inválida.' });
  }

  pedido.situacao = novaSituacao;
  pedido.atualizadoEm = new Date().toISOString();
  salvarBanco();
  res.json({ ok: true, pedido });
});

app.put('/api/pedidos/:id/cancelar', exigirLogin, (req, res) => {
  const pedido = db().pedidos.find(p => p.id === parseInt(req.params.id));
  if (!pedido) return res.status(404).json({ erro: 'Pedido não encontrado.' });

  const ehDono = pedido.clienteId === req.session.usuarioId;
  const usuario = usuarioAtual(req);
  const ehGerente = usuario && usuario.papel === 'gerente';

  if (!ehDono && !ehGerente) {
    return res.status(403).json({ erro: 'Você não pode cancelar este pedido.' });
  }
  if (pedido.situacao !== 'Recebido') {
    return res.status(400).json({ erro: 'Este pedido já está sendo preparado e não pode ser cancelado.' });
  }

  pedido.situacao = 'Cancelado';
  pedido.atualizadoEm = new Date().toISOString();
  salvarBanco();
  res.json({ ok: true, pedido });
});

app.get('/api/estatisticas', exigirGerente, (req, res) => {
  const hoje = new Date().toISOString().slice(0, 10);
  const pedidosHoje = db().pedidos.filter(p => p.criadoEm.slice(0, 10) === hoje && p.situacao !== 'Cancelado');
  const faturamentoHoje = pedidosHoje.reduce((soma, p) => soma + p.total, 0);
  const pendentes = db().pedidos.filter(p => ['Recebido', 'Preparando', 'Pronto', 'A caminho'].includes(p.situacao)).length;

  res.json({
    pedidosHoje: pedidosHoje.length,
    faturamentoHoje: Math.round(faturamentoHoje * 100) / 100,
    pendentes,
    totalPedidos: db().pedidos.length,
    totalPratos: db().pratos.filter(p => p.ativo).length
  });
});

function formatarPreco(valor) {

function formatarData(iso) {
  const d = new Date(iso);
  return d.toLocaleDateString('pt-BR') + ' às ' + d.toLocaleTimeString('pt-BR', { hour: '2-digit', minute: '2-digit' });

function escapar(texto) {
  const div = document.createElement('div');
  div.textContent = texto == null ? '' : String(texto);
  return div.innerHTML;
}

async function api(caminho, opcoes = {}) {
  try {
    const resposta = await fetch('/api' + caminho, {
      headers: { 'Content-Type': 'application/json' },
      ...opcoes,
      body: opcoes.body ? JSON.stringify(opcoes.body) : undefined
    });
    const dados = await resposta.json();
    if (!resposta.ok) throw new Error(dados.erro || 'Erro inesperado. Tente novamente.');
    return dados;
  } catch (erro) {
    if (erro.message === 'Failed to fetch') throw new Error('Sem conexão com o servidor. Verifique sua internet.');
    throw erro;
  }
}

async function enviarAuth() {
  const nome = document.getElementById('authNome').value.trim();
  const email = document.getElementById('authEmail').value.trim();
  const senha = document.getElementById('authSenha').value;
  const erroEl = document.getElementById('erroAuth');
  erroEl.style.display = 'none';

  try {
    const dados = modoCadastro
      ? await api('/cadastro', { method: 'POST', body: { nome, email, senha } })

    erroEl.textContent = erro.message;
    erroEl.style.display = 'block';
  }
}

async function sair() {

  usuario = null;

  location.reload();
}

function entrarNoSistema() {
  document.getElementById('telaAuth').style.display = 'none';
  document.getElementById('telaPrincipal').style.display = 'block';

  const ehGerente = usuario.papel === 'gerente';
  document.getElementById('olaUsuario').textContent = (ehGerente ? '👔 ' : '👤 ') + usuario.nome;
  document.getElementById('abasCliente').style.display = ehGerente ? 'none' : 'flex';
  document.getElementById('abasGerente').style.display = ehGerente ? 'flex' : 'none';
  document.getElementById('btnCarrinhoHeader').style.display = ehGerente ? 'none' : 'inline-block';

  document.querySelectorAll('.conteudo-aba').forEach(el => el.style.display = 'none');

  if (ehGerente) {
    mostrarAba('pedidosGerente');
  } else {
    mostrarAba('cardapio');
  }

  // Atualização automática a cada 10 segundos
  clearInterval(intervaloAtualizacao);
  intervaloAtualizacao = setInterval(() => {
    const abaVisivel = document.querySelector('.conteudo-aba:not([style*="none"])');
    if (!abaVisivel) return;
    const id = abaVisivel.id;
    if (id === 'aba-meusPedidos') carregarMeusPedidos(true);
    if (id === 'aba-pedidosGerente') carregarPedidosGerente(true);
  }, 10000);
}

function mostrarAba(nome) {
  document.querySelectorAll('.conteudo-aba').forEach(el => el.style.display = 'none');
  document.getElementById('aba-' + nome).style.display = 'block';
  document.querySelectorAll('.aba').forEach(a => a.classList.toggle('ativa', a.dataset.aba === nome));

  if (nome === 'cardapio') carregarCardapio();
  if (nome === 'meusPedidos') carregarMeusPedidos();
  if (nome === 'pedidosGerente') carregarPedidosGerente();
  if (nome === 'cardapioGerente') carregarCardapioGerente();
}

async function carregarCardapio() {
  const container = document.getElementById('aba-cardapio');
  container.innerHTML = '<div class="vazio"><div class="grande">⏳</div>Carregando cardápio...</div>';
  try {
    const { pratos } = await api('/cardapio');
    if (pratos.length === 0) {
      container.innerHTML = '<div class="vazio"><div class="grande">🍽️</div>O cardápio está sendo preparado.<br>Volte em instantes!</div>';
      return;
    }

    // Agrupa por categoria mantendo a ordem
    const categorias = {};
    pratos.forEach(p => {
      if (!categorias[p.categoria]) categorias[p.categoria] = [];
      categorias[p.categoria].push(p);
    });

    let html = '';
    for (const [categoria, itens] of Object.entries(categorias)) {
      html += `<h2 class="categoria-titulo">${escapar(categoria)}</h2><div class="grade-pratos">`;
      itens.forEach(p => {
        const foto = p.foto
          ? `<img src="${escapar(p.foto)}" alt="${escapar(p.nome)}" onerror="this.parentElement.innerHTML='🍽️'">`
          : '🍽️';
        html += `
          <div class="cartao-prato">
            <div class="foto-prato">${foto}</div>
            <div class="info-prato">
              <h3>${escapar(p.nome)}</h3>
              <p>${escapar(p.descricao)}</p>
              <div class="rodape-prato">
                <span class="preco">${formatarPreco(p.preco)}</span>
                <button class="btn-add" onclick="adicionarAoCarrinho(${p.id}, '${escapar(p.nome).replace(/'/g, "\\'")}', ${p.preco})">+ Adicionar</button>
              </div>
            </div>
          </div>`;
      });
      html += '</div>';
    }
    container.innerHTML = html;
  } catch (erro) {
    container.innerHTML = '<div class="vazio"><div class="grande">😕</div>' + escapar(erro.message) + '</div>';
  }
}

function adicionarAoCarrinho(id, nome, preco) {
  const existente = carrinho.find(i => i.pratoId === id);
  if (existente) existente.quantidade++;
  else carrinho.push({ pratoId: id, nome, preco, quantidade: 1 });
  atualizarIconeCarrinho();
  mostrarAviso(nome + ' adicionado ao carrinho ✓', 'sucesso');
}

function atualizarIconeCarrinho() {
  const total = carrinho.reduce((s, i) => s + i.quantidade, 0);
  const selo = document.getElementById('qtdCarrinho');
  selo.textContent = total;
  selo.style.display = total > 0 ? 'flex' : 'none';
}

function mudarQtd(id, delta) {
  const item = carrinho.find(i => i.pratoId === id);
  if (!item) return;
  item.quantidade += delta;
  if (item.quantidade <= 0) carrinho = carrinho.filter(i => i.pratoId !== id);
  renderizarCarrinho();
  atualizarIconeCarrinho();
}

function abrirCarrinho() {
  renderizarCarrinho();
  document.getElementById('modalCarrinho').classList.add('aberto');
}

function renderizarCarrinho() {
  const itensEl = document.getElementById('itensCarrinho');
  const rodapeEl = document.getElementById('rodapeCarrinho');
  const btnFinalizar = document.getElementById('btnFinalizar');

  if (carrinho.length === 0) {
    itensEl.innerHTML = '<div class="vazio"><div class="grande">🛒</div>Seu carrinho está vazio.</div>';
    rodapeEl.innerHTML = '';
    btnFinalizar.style.display = 'none';
    return;
  }

  let html = '';
  carrinho.forEach(i => {
    html += `
      <div class="item-carrinho">
        <span class="nome-item">${escapar(i.nome)}</span>
        <div class="controle-qtd">
          <button onclick="mudarQtd(${i.pratoId}, -1)">−</button>
          <strong>${i.quantidade}</strong>
          <button onclick="mudarQtd(${i.pratoId}, 1)">+</button>
        </div>
        <span class="subtotal-item">${formatarPreco(i.preco * i.quantidade)}</span>
      </div>`;
  });
  itensEl.innerHTML = html;

  const total = carrinho.reduce((s, i) => s + i.preco * i.quantidade, 0);
  rodapeEl.innerHTML = `
    <div class="campo" style="margin-top:16px;">
      <label>Endereço de entrega *</label>
      <input type="text" id="enderecoEntrega" maxlength="300" placeholder="Rua, número, bairro, complemento">
    </div>
    <div class="campo">
      <label>Observações (opcional)</label>
      <input type="text" id="obsPedido" maxlength="300" placeholder="Ex.: sem cebola, ponto da carne...">
    </div>
    <div class="total-carrinho"><span>Total:</span><span>${formatarPreco(total)}</span></div>`;
  btnFinalizar.style.display = 'inline-block';
}

async function finalizarPedido() {
  const endereco = (document.getElementById('enderecoEntrega') || {}).value || '';
  const observacao = (document.getElementById('obsPedido') || {}).value || '';
  try {
    await api('/pedidos', {
      method: 'POST',
      body: { itens: carrinho, endereco, observacao }
    });
    carrinho = [];
    atualizarIconeCarrinho();
    fecharModal('modalCarrinho');
    mostrarAviso('Pedido enviado com sucesso! 🎉 Acompanhe em "Meus Pedidos".', 'sucesso');
    mostrarAba('meusPedidos');
  } catch (erro) {
    mostrarAviso(erro.message, 'erro');
  }
}

const ETAPAS = ['Recebido', 'Preparando', 'A caminho', 'Entregue'];

function barraProgresso(situacao) {
  if (situacao === 'Cancelado') return '';
  let etapas = ETAPAS;
  // "Pronto" conta como etapa extra antes de "A caminho" em pedidos sem entrega
  let indiceAtual = etapas.indexOf(situacao);
  if (situacao === 'Pronto') indiceAtual = 2; // trata "Pronto" visualmente

  let html = '<div class="progresso">';
  etapas.forEach((etapa, i) => {
    const classe = i < indiceAtual ? 'feito' : (i === indiceAtual ? (situacao === 'Entregue' ? 'feito' : 'atual') : '');
    html += `<div class="passo ${classe}"><small>${etapa}</small></div>`;
    if (i < etapas.length - 1) html += `<div class="linha-passo ${i < indiceAtual ? 'feita' : ''}"></div>`;
  });
  html += '</div>';
  return html;
}

function classeSelo(situacao) {
  return 'selo-' + situacao.replace(' ', '');
}

async function carregarMeusPedidos(silencioso = false) {
  const container = document.getElementById('aba-meusPedidos');
  if (!silencioso) container.innerHTML = '<div class="vazio"><div class="grande">⏳</div>Carregando seus pedidos...</div>';
  try {
    const { pedidos } = await api('/meus-pedidos');
    if (pedidos.length === 0) {
      container.innerHTML = '<div class="vazio"><div class="grande">🧾</div>Você ainda não fez nenhum pedido.<br>Que tal dar uma olhada no cardápio? 😋</div>';
      return;
    }
    container.innerHTML = pedidos.map(p => `
      <div class="cartao-pedido">
        <div class="topo-pedido">
          <div>
            <div class="num-pedido">Pedido #${p.id}</div>
            <div class="data-pedido">${formatarData(p.criadoEm)}</div>
          </div>
          <span class="selo ${classeSelo(p.situacao)}">${escapar(p.situacao)}</span>
        </div>
        ${barraProgresso(p.situacao)}
        <div class="itens-pedido">
          ${p.itens.map(i => `${i.quantidade}× ${escapar(i.nome)} — ${formatarPreco(i.preco * i.quantidade)}`).join('<br>')}
        </div>
        ${p.observacao ? `<div class="endereco-pedido">📝 ${escapar(p.observacao)}</div>` : ''}
        <div class="rodape-pedido">
          <span class="endereco-pedido">📍 ${escapar(p.endereco)}</span>
          <span class="total-pedido">${formatarPreco(p.total)}</span>
        </div>
        ${p.situacao === 'Recebido' ? `<div style="margin-top:10px;"><button class="btn-perigo" onclick="cancelarPedido(${p.id})">Cancelar pedido</button></div>` : ''}
      </div>`).join('');
  } catch (erro) {
    if (!silencioso) container.innerHTML = '<div class="vazio"><div class="grande">😕</div>' + escapar(erro.message) + '</div>';
  }
}

async function cancelarPedido(id) {
  if (!confirm('Tem certeza que deseja cancelar o pedido #' + id + '?')) return;
  try {
    await api('/pedidos/' + id + '/cancelar', { method: 'PUT' });
    mostrarAviso('Pedido cancelado.', 'sucesso');
    carregarMeusPedidos();
  } catch (erro) {
    mostrarAviso(erro.message, 'erro');
  }
}

const PROXIMA_SITUACAO = {
  'Recebido': 'Preparando',
  'Preparando': 'Pronto',
  'Pronto': 'A caminho',
  'A caminho': 'Entregue'
};

async function carregarPedidosGerente(silencioso = false) {
  const container = document.getElementById('aba-pedidosGerente');
  if (!silencioso) container.innerHTML = '<div class="vazio"><div class="grande">⏳</div>Carregando pedidos...</div>';
  try {
    const [{ pedidos }, stats] = await Promise.all([api('/pedidos'), api('/estatisticas')]);

    let html = `
      <div class="estatisticas">
        <div class="estat"><div class="numero">${stats.pedidosHoje}</div><div class="rotulo">Pedidos hoje</div></div>
        <div class="estat"><div class="numero">${formatarPreco(stats.faturamentoHoje)}</div><div class="rotulo">Faturamento hoje</div></div>
        <div class="estat"><div class="numero">${stats.pendentes}</div><div class="rotulo">Pedidos em andamento</div></div>
        <div class="estat"><div class="numero">${stats.totalPedidos}</div><div class="rotulo">Total de pedidos</div></div>
      </div>`;

    if (pedidos.length === 0) {
      html += '<div class="vazio"><div class="grande">📋</div>Nenhum pedido ainda.<br>Quando um cliente pedir, aparecerá aqui automaticamente.</div>';
      container.innerHTML = html;
      return;
    }

    html += pedidos.map(p => {
      const proxima = PROXIMA_SITUACAO[p.situacao];
      const emAndamento = ['Recebido', 'Preparando', 'Pronto', 'A caminho'].includes(p.situacao);
      return `
      <div class="cartao-pedido">
        <div class="topo-pedido">
          <div>
            <div class="num-pedido">Pedido #${p.id} — ${escapar(p.clienteNome)}</div>
            <div class="data-pedido">${formatarData(p.criadoEm)} · ${escapar(p.clienteEmail)}</div>
          </div>
          <span class="selo ${classeSelo(p.situacao)}">${escapar(p.situacao)}</span>
        </div>
        <div class="itens-pedido">
          ${p.itens.map(i => `${i.quantidade}× ${escapar(i.nome)} — ${formatarPreco(i.preco * i.quantidade)}`).join('<br>')}
        </div>
        ${p.observacao ? `<div class="endereco-pedido">📝 ${escapar(p.observacao)}</div>` : ''}
        <div class="rodape-pedido">
          <span class="endereco-pedido">📍 ${escapar(p.endereco)}</span>
          <span class="total-pedido">${formatarPreco(p.total)}</span>
        </div>
        ${emAndamento ? `
        <div class="acoes-situacao" style="margin-top:12px;">
          ${proxima ? `<button class="b-avancar" onclick="mudarSituacao(${p.id}, '${proxima}')">✔ Marcar como "${proxima}"</button>` : ''}
          ${p.situacao === 'Pronto' ? `<button class="b-avancar" style="background:#8e44ad;" onclick="mudarSituacao(${p.id}, 'Entregue')">✔ Entregue no balcão</button>` : ''}
          <button class="b-cancelar-ped" onclick="cancelarPedidoGerente(${p.id})">Cancelar</button>
        </div>` : ''}
      </div>`;
    }).join('');

    container.innerHTML = html;
  } catch (erro) {
    if (!silencioso) container.innerHTML = '<div class="vazio"><div class="grande">😕</div>' + escapar(erro.message) + '</div>';
  }
}

function abrirModalPrato(prato = null) {
  document.getElementById('erroPrato').style.display = 'none';
  document.getElementById('tituloModalPrato').textContent = prato ? 'Editar Prato' : 'Cadastrar Prato';
  document.getElementById('pratoId').value = prato ? prato.id : '';
  document.getElementById('pratoNome').value = prato ? prato.nome : '';
  document.getElementById('pratoDescricao').value = prato ? (prato.descricao || '') : '';
  document.getElementById('pratoPreco').value = prato ? prato.preco : '';
  document.getElementById('pratoCategoria').value = prato ? prato.categoria : '';
  document.getElementById('pratoFoto').value = prato ? (prato.foto || '') : '';
  document.getElementById('pratoAtivo').checked = prato ? prato.ativo : true;
  document.getElementById('modalPrato').classList.add('aberto');
}

async function salvarPrato() {
  const id = document.getElementById('pratoId').value;
  const corpo = {
    nome: document.getElementById('pratoNome').value,
    descricao: document.getElementById('pratoDescricao').value,
    preco: document.getElementById('pratoPreco').value,
    categoria: document.getElementById('pratoCategoria').value,
    foto: document.getElementById('pratoFoto').value,
    ativo: document.getElementById('pratoAtivo').checked
  };
  const erroEl = document.getElementById('erroPrato');
  erroEl.style.display = 'none';
  try {
    if (id) await api('/pratos/' + id, { method: 'PUT', body: corpo });
    else await api('/pratos', { method: 'POST', body: corpo });
    fecharModal('modalPrato');
    mostrarAviso(id ? 'Prato atualizado! ✓' : 'Prato cadastrado! ✓', 'sucesso');
    carregarCardapioGerente();
  } catch (erro) {
    erroEl.textContent = erro.message;
    erroEl.style.display = 'block';
  }
}

async function removerPrato(id, nome) {
  if (!confirm(`Remover "${nome}" do cardápio? Esta ação não pode ser desfeita.`)) return;
  try {
    await api('/pratos/' + id, { method: 'DELETE' });
    mostrarAviso('Prato removido.', 'sucesso');
    carregarCardapioGerente();
  } catch (erro) {
    mostrarAviso(erro.message, 'erro');
  }
}
